# SRGAN

首次将GAN应用于超分辨率重建任务，提出了SRGAN模型。该模型通过引入感知损失函数来提高生成图像的视觉质量。SRGAN的核心思想是使用对抗性训练来生成更真实、更高质量的图像。

生成器和判别器交替训练

生成器的损失函数用内容感知损失和对抗损失的加权和定义

内容感知函数不用像素级的MSR，而是用VGG网络的特征图来计算内容损失

判别器的损失函数用二元交叉熵损失定义

# realSR

提出了新的数据集采集方法：用同一个相机在同一视角，通过不同的焦距拍摄同一场景，生成高分辨率和低分辨率图像对。

在原有SR基础模型的基础上，加入了KEN来估计模糊核，把这个模糊核当作信息输入到生成器中，生成器可以根据模糊核来生成更清晰的图像。



# ESRGAN
* SRGAN生成图像存在伪影（artifact），细节有时不够自然。
* 损失函数设计不够精细，生成效果受限。
* 判别器和网络结构仍有提升空间。

删除了BN层，换成了RRDB，去除了伪影

损失函数改成了像素级MSE、感知损失和对抗损失的加权和

改变了判别器的输出，改成了相对概率值，一张图比另一张图更真实的概率

同时用谱归一化来让训练过程更加稳定
