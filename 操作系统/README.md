# 操作系统
## 老师选择
我选的是gxl，引用icu上面的一句评价，这个老师有种把操作系统学透了，讲课信手拈来的感觉。上课的知识密度不是很高，因为这个老师夹杂了很多的理解，经常举例子给你讲解。但是上课的节奏很慢，平时去听的话收获很多，但是感觉去上课有点奢侈了。

其他老师好像都差不多，然后实验是统一给分，改卷应该也是一样，所以无所谓。老宫也会把上课的录屏放在网站上面给大家去学习。不过听说老宫的给分比其他老师要好，所以还是尽可能老宫。

## 课程内容
平时分和考试分五五开，平时分主要就是实验分还有一个论文展示。

详细课程内容我没怎么听，考前两天看视频速成的。

## 实验相关
实验三人一组，基本上两三个星期一个实验，需要完成一个小操作系统的各个功能部分。基本上分工之后提前一到两天去完成作业即可，但是要注意答辩内容，大多答案出现在实验指导书上面，所以要精读实验指导书！也可以去偷听其他组的答辩问题hhh。

每次实验答辩前一两天会发一个选助教的，发送的时间比较随机，可能你在路上走路就发出来了，导致选到的助教不好，后人可以和助教商量一下能不能提前通知什么时候发送选助教的消息。

我们的实验开源仓库：https://github.com/Absurdaaa/OS

## 考试准备
我们学校的操作系统的内容和大部分学校的操作系统内容不太一样，考前一定要看清楚考试范围。考试范围主要是老师上课讲过的内容，还会有大约40分的实验代码相关的内容，可以看lhz的回忆版，我今年是真不想回忆了。

我是超级速成的，直接拿lhz的笔记去看gxl的录屏。建议大家可以刷一些考研题来熟悉一下题型，毕竟平时没有作业参考，是不知道考什么样子的，导致我遇到一道题完全不会做。
