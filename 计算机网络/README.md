# 计算机网络
## 老师选择
徐张or吴英？
无脑徐张，给分好。两位老师的讲课顺序是相反的，所以两个老师的讲课内容差别不少，而且徐张似乎讲的多一些，建议在复习之前去对其一下重点和讲课的内容，防止多复习了

## 课程资料
在25年7月，徐张出版了一本教材，本学期的ppt也是和教材配套的，建议购买教材，复习的时候结合教材和ppt一起复习。教材讲的相当清晰。然后课后题和考试题的风格十分相似，在复习资料里面我放了课后题的扫描版，建议考前刷刷。

## 实验部分
实验部分并不困难，但是千万不要迟交，血的教训，我记错了截止时间，迟交了两个小时，第二次实验只能拿到70%的分数，最后只拿了69，导致平时分数被扣了大约七八分，但是好在期末考试不错，最后老师把我捞到了总评85分（看来我期末考试做的还挺diao的，虽然我空了蛮多的）。还得是徐老师，xjd是我妈！

现在回头来看实验部分其实感觉做的很粗糙，和课内不是很对应，毕竟是没学就直接拿ai来做，建议完成实验之前去好好预习一下课内内容，理解清楚再去做实验。

## 复习建议
1. 认真复习课后题
2. 复习ppt和教材
可能需要拿一个星期来预习，如果平时没有学习的话。然后内容也比较多，建议早点开始复习。最好把课本过一遍。
