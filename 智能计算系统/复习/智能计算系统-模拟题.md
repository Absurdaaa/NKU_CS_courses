简答题要点：

1. MSE 梯度在 sigmoid 饱和区会受 `σ'(z)` 影响而变小，更新慢；交叉熵与 sigmoid 配合时可抵消相关导数项，分类训练更稳定、更快。
2. RNN 反向传播链条长，雅可比连乘导致梯度消失/爆炸；LSTM 用单元状态和遗忘/输入/输出门控制信息流；GRU 用更新门和重置门简化门控，参数更少。
3. 静态图先构图再执行，利于全局优化、性能好，但调试不方便；动态图边执行边构图，灵活、易调试，但全局优化较难。

程序设计题评分要点：

- 模型结构正确 6 分。
- 维度处理正确 3 分。
- 训练迭代流程完整 4 分。
- 代码风格清晰 2 分。

参考代码：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SmallCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 16, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(16, 32, kernel_size=3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        self.fc = nn.Linear(32 * 8 * 8, num_classes)

    def forward(self, x):
        x = self.pool(F.relu(self.conv1(x)))  # 32 -> 16
        x = self.pool(F.relu(self.conv2(x)))  # 16 -> 8
        x = torch.flatten(x, 1)
        return self.fc(x)

model = SmallCNN()
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

images = torch.randn(16, 3, 32, 32)
labels = torch.randint(0, 10, (16,))

optimizer.zero_grad()
logits = model(images)
loss = criterion(logits, labels)
loss.backward()
optimizer.step()
```

分析问答题要点：

- 数据并行每卡有完整模型副本，参数、梯度、优化器状态重复存储。
- ZeRO 将优化器状态、梯度、参数分片到不同 GPU，用时通过通信重建，减少冗余；可进一步 Offload 到 CPU/NVMe。
- 稳定性优化包括定期 checkpoint、故障后回滚恢复、弹性训练、冗余计算。

程序设计题参考答案：

```python
def can_broadcast(shape_a, shape_b):
    a = list(shape_a)
    b = list(shape_b)
    n = max(len(a), len(b))
    a = [1] * (n - len(a)) + a
    b = [1] * (n - len(b)) + b

    out = []
    for x, y in zip(a, b):
        if x == y:
            out.append(x)
        elif x == 1:
            out.append(y)
        elif y == 1:
            out.append(x)
        else:
            return None
    return tuple(out)
```

评分要点：末尾对齐/前面补 1 4 分；逐维合法性判断 5 分；返回正确结果 4 分；边界情况和代码清晰 2 分。

分析问答题要点：

- 能力：Decoder-only 适合自回归生成，in-context learning 强，zero-shot/few-shot 泛化好。
- 注意力结构：causal attention 防止看未来，下三角结构具有满秩性质，并有隐式位置建模效果。
- 推理效率：可复用 KV cache，decode 阶段每次只算新 token。
- 系统优化：Megatron、FlashAttention 等对 causal attention 支持成熟，工程生态完善。

### 模拟卷三参考答案

选择题：1.D 2.C 3.A 4.B 5.B 6.A 7.B 8.A 9.A 10.B

填空题：

1. `TP + FP`
2. 并集
3. FFN/前馈网络
4. 算子

简答题要点：

1. Tensor 支持 GPU/DLP、自动求导和计算图；NumPy ndarray 原生 CPU 运算，不支持框架自动求导。`torch.from_numpy` 和 `.numpy()` 通常共享内存；GPU tensor 需先 `.cpu()`。
2. PTQ 是预训练后用校准数据量化，无需训练；QAT 是量化后微调/再训练，前向模拟量化；量化训练从初始化开始全程低位宽训练，可同时加速训练和推理但实现难。
3. DLP 两大特点：IO 直接连接外部；增设便笺存储器并通过 DMA 访问 DRAM。优势是减少通用处理器大量 load/store、控制、寻址和 cache 开销，一条指令可完成更大粒度矩阵计算。

程序设计题参考答案：

```python
def _pair(x):
    if isinstance(x, tuple):
        return x
    return (x, x)

def conv2d_output_shape(h, w, kh, kw, padding=0, stride=1):
    ph, pw = _pair(padding)
    sh, sw = _pair(stride)
    out_h = (h + 2 * ph - kh) // sh + 1
    out_w = (w + 2 * pw - kw) // sw + 1
    return out_h, out_w

assert conv2d_output_shape(32, 32, 3, 3, padding=1, stride=1) == (32, 32)
assert conv2d_output_shape(5, 5, 3, 1, padding=(1, 0), stride=2) == (3, 3)
```

评分要点：公式正确 6 分；支持整数和 tuple 参数 4 分；高宽分别计算 3 分；代码清晰和测试 2 分。

分析问答题要点：

- `Conv + BatchNorm + ReLU` 合并属于图级优化，因为它改变计算图中的算子关系和数据流，不深入单个算子的循环实现。
- 循环分块、向量化、自动调优属于算子级优化，因为它们针对底层 kernel/循环程序和硬件访存计算特性。
- 深度学习编译可降低人工适配新硬件和新算子的维护成本，通过图级全局优化与算子级自动调优提高硬件利用率和运行性能。
