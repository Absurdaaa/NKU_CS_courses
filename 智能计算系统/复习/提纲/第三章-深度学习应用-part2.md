## 一、Driving Example:图像风格迁移(P3–P13)
- **图像风格迁移(Image Style Transfer)**:给内容图 p、风格图 a,调整随机噪声图 x,使其**既保内容、又有风格**。用 ImageNet 上训练好的 **VGG19**(去掉全连接层和 softmax)提特征。P5–6
- **内容损失**:只取 conv4 单层,算生成图特征 `F` 与内容图特征 `P` 的欧式距离。P6
- **风格损失**:取 conv1~conv5 共 5 层,用 **Gram 矩阵(相关矩阵/特征图内积)** 表示风格,各层权重 `wₗ=0.2`。P7
- **优化对象是图像 x 本身**:`x ← x − ∂L_total/∂x`(对像素做梯度下降)。**α/β 越大,内容越具象**。P8–9
- ⭐**实时风格迁移(Real-Time)**:原始方法每张图都要前馈+反馈调优,无法实时。改进:提前训练好**图像转换网络**,推理时只需一次前馈,无需反向。参考 DCGAN(步长卷积代替 pooling、BN+ReLU)+ 残差结构。P10–12

## 二、循环神经网络:序列与语言模型(P15–P26)
- ⭐**为什么需要 RNN**:序列数据(语音/文字/视频)按时序输入,前后数据**不独立、有相关性**,网络需有"存储"信息的能力。应用:机器翻译、图片描述、视频标注、视觉问答。P15–16
- ⭐**语言模型**:估计序列发生的概率分布,链式分解 `P(x₁,…,xₜ)=∏ P(xᵢ|x₁,…,xᵢ₋₁)`。如"中国的首都是北京"概率高。P18
- **处理三步**:分词(tokenization)→ 嵌入(embedding)→ 网络模型。P19
- ⭐**token(词元)**:文本的基本单位,分词后获得;**词表**=所有词元的列表。**大模型按 token 计费**。粒度:character / word / **subword**。P20–21
- ⭐**BPE(字节对编码)**:subword 分词主流方法,核心=**不断把最频繁出现的一对词元合并**。步骤:预分词→基础词表→合并。GPT 词表 40478 = 478 基础字符 + 40000 次合并。P22
- ⭐**embedding(词嵌入)**:把离散 token 转成**固定维度连续向量**,捕捉语义。P23
  - **one-hot**:长 N 向量、索引位为 1。缺陷:任意两词余弦相似度为 0(表达不了相似度)、维度高、稀疏。P24
  - **word2vec**:稠密低维、能表达相似性(`King−Man+Woman≈Queen`);用大量语料**无监督预训练**;含 CBOW 和 Skip-gram。P25
  - **Transformer 的 embedding**:学习一个 embedding 矩阵,one-hot 输入下矩阵乘法**简化为查表**,训练中学权重。P26

## 三、RNN 结构与训练(P27–P35)
- ⭐**RNN 结构**:带自反馈神经元,处理任意长序列。隐状态 `h(t)=f(W·h(t−1)+U·x(t)+b)`,f 常用 tanh/ReLU;输出 `ŷ(t)=softmax(V·h(t)+c)`。P27,P29
- **三特性**:**sequence**(前后输入不独立)、**recurrent**(每时刻操作相同、**参数 W/U/V/b 共享**)、**memory**(h(t) 记忆 t 之前信息,理论无限、实际有限)。P28
- **多种输入-输出结构**:序列作输出(看图说话)、序列作输入(情感分析)、序列→序列(机器翻译)、同步序列→序列(逐帧视频分类);序列长度无需预先定义。P31
- ◆**BPTT(随时间反向传播)**:单时刻损失 `L(t)=−y(t)·ln ŷ(t)`,整序列 `L=Σ L(t)`;`∂L/∂W` 需对各时刻、各历史步 k 求和(链式逐层回传)。P32
- ⭐◆**梯度消失/爆炸**:令 γ 为相邻隐状态雅可比的范数,t≫k 时 γ→∞ 则**梯度爆炸**、γ→0 则**梯度消失**;故 RNN **只能学短期依赖**(如近的"sky"可预测,远的"Italy…Italian"学不到)。P33,P35
- ⭐**改进手段**:梯度爆炸→**梯度截断**;梯度消失→**模型改进(LSTM、GRU)**。P34

## 四、LSTM 与 GRU(P36–P40)
- ⭐**LSTM(长短期记忆)**:在 RNN 基础上增加**单元状态 c(t)**(信息传送带,只有少量线性运算,易让信息不变流动)+ **门限**控制增删信息。P36
  - **三门**:**遗忘门 f**(记住前一时刻单元状态多少)、**输入门 i**(写入多少新信息)、**输出门 o**(输出多少当前单元状态)。P37
  - **变体**:窥视孔连接(门值也依赖 c(t−1))、耦合输入门和遗忘门(遗忘与新增一起决定)。P38
- ⭐**GRU(门控循环单元)**:合并单元状态与隐状态、合并遗忘门+输入门为**更新门 z**,无输出门;**重置门 r** 决定保留多少历史。P39
- **LSTM vs GRU**:无定论。**GRU 参数少、训练快**;数据足够时 **LSTM 表征更强**。P40

## 五、Seq2Seq 与注意力机制(P42–P52)
- ⭐**Seq2Seq(序列到序列)**:特殊语言模型,**编码器(encoder)** 把输入编成语义编码,**解码器(decoder)** 据此输出;适用于**输入输出不等长**。应用:机器翻译、对话、自动文摘。传统用 RNN/LSTM 作编/解码器。P42–44
- ⭐**Seq2Seq 缺陷(为何要注意力)**:① 固定长度语义编码**存不下长序列**全部信息;② 语义编码各元素**权重相同**,无法区分重要程度。P45
- ⭐**注意力机制**:对输入各部分赋予**不同权重**,抽取关键信息。优势:聚焦关键、判断更准;**可并行,比 RNN 序列计算快**。P46–47
  - ◆两步:① 算相似度 `αᵢⱼ=softmax(a(sᵢ₋₁, hⱼ))`;② 注意力汇聚 `c(i)=Σⱼ αᵢⱼ·h(j)`。P47
- ⭐◆**缩放点积注意力(Scaled Dot-Product Attention)**:输入 **查询 Q、键 K、值 V**(每个 V 与一个 K 配对),据 Q、K 相似度算 V 的权重。
  - 公式:`Attention(Q,K,V)=softmax((QKᵀ/√dₖ)+Mask)·V`。P48
  - 过程:Q·Kᵀ 内积得词间相关→scale/Mask/softmax 得权重矩阵→乘 V(注意力汇聚)。P48
  - ◆**为何除以 √dₖ**:q、k 均值 0 方差 1,内积方差为 dₖ;dₖ 大时内积偏大,除 √dₖ 使方差归 1,**获得较大 softmax 梯度,防梯度消失**。P48
- ⭐**自注意力(self-attention)**:Q、K、V 来源**同一组输入**,`Q=I·Wᵠ, K=I·Wᴷ, V=I·Wⱽ`;擅长捕捉序列**内部**相关性(传统注意力只捕捉输入-输出间)。P49–50
- ⭐◆**多头注意力(Multi-Head)**:对 QKV 做 h 组不同线性变换→并行算注意力→拼接后再线性映射。`MultiHead(Q,K,V)=Concat(head₁,…,headₕ)·Wᴼ`,`headᵢ=Attention(Q·Wᵢᵠ,K·Wᵢᴷ,V·Wᵢⱽ)`。原理:学不同知识再组合。P51

## 六、Transformer 结构(P53–P69)
- ⭐**结构特点**:遵循 Seq2Seq(编码器+解码器),**去掉 RNN**(效率低、不能并行),**大量重复使用 attention**。来源:Vaswani《Attention is all you need》NeurIPS 2017。P53
- **输入处理**:词元嵌入(查 embedding 矩阵)+ **位置编码**。P54,P67
- ⭐**位置编码(Position Encoding)**:用波长从 2π 到 10000·2π 的不同**正弦/余弦函数**计算,输入为位置 pos 和维度 2i / 2i+1;与嵌入相加。P55
- ⭐**编码器(Encoder)**:N=6 个相同层,每层两子层=**多头自注意力(QKV 同源、无 mask)** + **前馈网络(FFN)**,每子层加**残差连接 + 层归一化**。P56–57
- **层归一化(Layer Norm)**:沿 embedding 方向对**每个嵌入向量**标准化为均值0方差1。作用:缓解梯度消失、加快收敛、类似正则防过拟合、可用大学习率。P58
- **FFN 前馈子层**:**先升维再降维 512→2048→512**,用 ReLU 引入非线性;每个位置共享同一线性权重。P59
- ⭐**解码器(Decoder)**:N=6 个相同层,每层**三子层**=**带 mask 的多头自注意力** + **交叉注意力(cross-attention)** + FFN,各加残差+LN。P60,P62–63
  - **带 mask 自注意力**:捕捉输出序列内部关系,**mask 去掉当前位置后面 token 的影响**(满足自回归);`Attention=softmax(QKᵀ/√dₖ + M)·V`,**M 右上角设为 −inf**。P62
  - **交叉注意力**:捕捉输入-输出间关系;**Q 来自解码器自注意力输出,K/V 来自编码器输出**;残差来源于 Q。P63,P69
- **解码器输入/训练推理差异**:输入=编码器输出 + 上一位置解码器输出。**训练有 label(右移一位),可并行**;**推理无 label,逐位置解码,无法并行**。P61
- **输出**:线性变换(全连接)映射到词汇表空间 → softmax 输出下一词元概率分布。P64
- ◆**规模参数**(会查表):base = N6/d512/dff2048/h8/dₖ64/**65M**;large = N6/d1024/dff4096/h16/dₖ64/**213M**。P63

## 七、大模型架构三分类(P70–P76)
- ⭐**编码器-解码器(Encoder-Decoder)**:用于 Seq2Seq(机器翻译、对话);代表:原始 Transformer、Google T5、GLM。P70
- ⭐**仅编码器(Encoder-Only)**:只编码不生成,用于文本分类、情感分析等;代表:**Google BERT**。P70
- ⭐**仅解码器(Decoder-Only)**:序列生成,从开头扩展新内容;代表:**OpenAI GPT、Meta LLaMA、DeepSeek**。P70

### BERT(Encoder-Only)P71–P75
- ⭐**BERT**:取 Transformer **编码器**部分双向连接;每层=多头自注意力(**无 mask**)+ FFN。**双向**=每个位置能看序列前后(无 mask)。P71
- **训练**:**预训练**用海量无标签语料自监督(完形填空 MLM + 判断两句是否有上下文 NSP);**微调**用下游有标签数据,迁移到分类/序列标注/检索等。P72
- 规模:base 12层/768/110M;large 24层/1024/340M。P71
- **BERT vs GPT**:参数量相近,但 **BERT 预训练数据约为 GPT 的 4 倍**,在很多**理解类**下游任务超过 GPT。P74
- **优势/不足**:优势=无监督预训练、MLM 获双向特征、易微调迁移、适合 NLU;不足=无自回归预训练、缺解码器,**不适合生成任务(NLG)**,只适合句/段级、不适合文档级。P75

## 八、GPT 系列与 Decoder-Only(P76–P87)
- ⭐**GPT(Decoder-Only)**:提出 NLP **预训练-微调统一框架**;用 Transformer 解码器(带 mask 自注意力 + FFN),12层/12头/768维/dff3072/context 512。P77
  - **预训练(无监督)**:自回归,给前 N−1 词预测第 N 词(第 N 词即标签),mask 保证只用历史。P78
  - **微调(有监督)**:新加线性层 Wy 从头训、其余微调;目标=下游任务目标 + 预训练语言模型目标加权求和。P79
- **GPT-2**:核心=**无需特定任务监督微调**,预训练阶段用语言模型建模多种下游任务(任务描述+输入+输出);结构改为 **Pre-LN**(LN 放子层前,梯度范数稳定,利于优化;末尾加额外 LN);更大规模(数据 5GB→40GB)。P80–82
- **GPT-3**:沿用 GPT-2 结构,规模大幅提升(96层/96头/d12288/**175B 参数/45TB 数据**)。P83
  - **尺度定律(Scaling Law)**:增大算力/数据/参数,Loss 单调下降。**涌现能力(Emergent ability)**:规模到一定程度(~60B)能力出现飞跃。P84
  - **in-context learning**:zero-shot(仅任务描述)/ one-shot(+1 示例)/ few-shot(+若干示例),**无需更新参数**(区别于传统微调)。P85
- **InstructGPT**:用**人类反馈强化学习(RLHF)** 微调。三步:① 人工标注监督微调 GPT-3;② 训练奖励模型;③ 用奖励模型 reward + **PPO** 微调。P86
- **GPT 后续**:ChatGPT(GPT3.5+RLHF)→ GPT-4(AGI 火花)→ GPT-4o(多模态)→ o1/o3(通用推理)。P87

## 九、LLaMA 与大模型组件改进(P88–P94)
- **LLaMA 系列**:Meta 开源基础模型(LLaMa→Llama2→Llama3,参数/数据/上下文/词表递增),decoder-only。四点改动:**前置 RMSNorm**、**SwiGLU 激活**、**旋转位置编码 RoPE**、部分用**分组查询注意力 GQA**。P88–89
- **RoPE(旋转位置编码)**:用旋转矩阵编码绝对位置,在自注意力中注入**相对位置**信息(每层都注入);优势:支持长序列,相对距离越大依赖越低。偶数维可拆为二维形式拼接。P90–91
- **激活函数**:Swish `=x·sigmoid(x)`(更平滑、收敛快、抗过拟合);**SwiGLU** `=SiLU(xW+b)·(xV+c)`(Llama3、DeepSeek 用)。P92
- **RMSNorm**:LayerNorm 含平移+缩放,RMSNorm **去平移、只留缩放**,效果相当、计算更简、更稳。P93
- **Attention 变体**:**MHA**(每头独立 KV)→ **GQA**(Q 分组、组内共享 KV)→ **MQA**(所有 Q 共享 KV);GQA 在性能与速度间 trade-off。P94

## 十、Decoder-Only 推理、DeepSeek 与"为何成主流"(P95–P104)
- **Decoder-Only 推理两阶段**:**Prefill**(分析全部提示词、生成第一个词元,用时长,缓存 K/V 即 **KV-Cache**)→ **Decode**(自回归生成直到终止符)。P95
- **KV Cache**:缓存历史 K/V,新 token 只需计算自身的 attention,加速推理。P96
- **DeepSeek 系列**:基座=Decoder-only Transformer + 混合专家(MoE)。脉络:DeepSeek-LLM(LLaMA 架构+扩展法则)、MoE(细粒度专家分割+共享专家隔离)、Math(GRPO 组相对策略优化)、V2(**多头潜在注意力 MLA**)、V3(多 Token 预测+混合精度)、R1(无监督强化学习+推理蒸馏)。P97
  - **DeepSeek-V3**:671B 参数、每 token 激活 37B;61 层,第 4 层起 FFN 换 MoE;MLA(KV 压缩 512/Q 压缩 1536/RoPE 维 64);SwiGLU。P98
  - **MLA**:性能优于 MHA,KV cache 远低于 MHA(小 MoE 约 14%、大 MoE 约 4%)。P99–101
  - **V3 的 MoE**:每 MoE = 1 共享专家 + 256 路由专家,每 token 激活 8 个路由专家、最多 4 节点。P102
- ⭐**为什么 Decoder-Only 成为主流**(重点论述):P103–104
  - **in-context learning 更强**:prompt 直接作用于 decoder 每层参数,无需经编码器转换,微调信号更强。
  - **注意力满秩**:双向 attention 矩阵易退化为低秩,而 causal attention 是下三角矩阵**必满秩**,建模能力更强。
  - causal attention 具**隐式位置编码**功能。
  - **效率高**:可一直复用 KV-Cache;Megatron、Flash Attention 对 causal attention 支持更好。
  - **实验证明**:zero-shot 泛化更好、in-context learning(few-shot)能力更强。
