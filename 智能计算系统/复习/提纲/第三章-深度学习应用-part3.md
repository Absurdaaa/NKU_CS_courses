## 一、Transformer 在图像处理中的应用(P4–P14)

- **发展脉络**:2017 Transformer → 2020 DETR/ViT → 2021 Swin-T/CLIP → 2022 Stable Diffusion/BLIP → 2024 Sora/DiT/SD3。P4
- ⭐**DETR(Detection Transformer)**:把**目标检测视为集合预测问题**(里程碑),摆脱 NMS、anchor 等手工部件。流程:①CNN backbone 提特征 → ②特征序列输入 Transformer 编解码器 → ③FFN 输出最终预测。P6–7
- ⭐**ViT(Vision Transformer)**:把图像分类转为序列问题。难点:像素当词元序列太长(224×224→50176,是 BERT 的100倍)。改进:**像素点→图像块(patch)**。P8–9
  - 流程:①划分固定大小 patches → ②展平成一维向量 → ③加 Position embedding → ④加 Class token → ⑤输入 Transformer Encoder → ⑥分类。例:224/16 得 196 个 patch,`[196,768]` + class token `[1,768]`。P10
- **Swin Transformer**:基于**移动窗口的分层结构**;与 ViT 区别在于划分 windows、**只在 window 内做 self-attention**,作为 CV 通用骨干网络。P11–12
  - 随 block 堆叠逐渐增大 window 增加尺度信息;交替用 regular window 与 **shifted window**(边界向右下移半个 window)增加窗口间联系。P13
  - **W-MSA** 省计算但牺牲窗口间建模;**SW-MSA** 增加窗口间联系,用 cyclic shift + masked MSA 高效计算。P14

## 二、面向图像生成的大模型(P15–P62)

### 生成模型基础(P15–P17)
- **判别模型 vs 生成模型**:判别学到数据的模式/特征(图像识别);生成学到数据的**分布**(图像生成)。P15
- **生成模型思想**:同类图像看作分布 `p_data`,生成模型从概率分布中找一个与 `p_data` 相近的 `p_θ`,再从 `p_θ` 采样新样本。P16
- **生成模型分类**:GAN、VAE、Flow-based、Diffusion。P17

### ⭐ 生成对抗网络 GAN(P18–P30)
- **GAN**:2014 Ian Goodfellow 提出,从训练样本学出新样本,学到真实样本集的数据分布。P18
- **两部分**:**生成器(伪装者)** 生成以假乱真样本使判别输出→0.5;**判别器(警察)** 判断真假,真样本输出→1、生成样本→0。P19
- **训练**:交替迭代——先更新判别网络分清真假,再更新生成网络让假样本被判为真。P20
- ⭐**极小极大博弈(零和博弈)**:优化 D 使真样本→1、生成样本→0;优化 G 使 `(1−D(G(z)))` 越小越好(生成样本被判为接近1)。P21
- **优点**:整体一个损失函数,无需分别指定,通用性强。**问题**:**梯度消失**(判别器高置信识破时 G 梯度消失,应对:改 G 的代价函数)、**模式崩溃**(只生成几种模式、缺多样性)。P22
- **模式崩溃**:损失函数对假样本惩罚巨大,一类假样本骗过判别器后 G 趋向生成相似样本;应对 **WGAN**(更平滑损失/Wasserstein)。P23
- **GAN 结构家族**:卷积 GAN(DCGAN/ResGAN/SRGAN/CycleGAN)、条件 GAN(CGAN/InfoGAN)、集成推断(BiGAN)、对抗自编码器(VAE-GAN)。P25
  - **DCGAN**:用卷积取代全连接;步长卷积/小数步长卷积取代池化做上下采样;用 batchnorm 防模式崩溃;G 输出用 Tanh、其它层 ReLU,D 全用 LeakyReLU。P26
- ⭐**条件 GAN(CGAN)**:原始 GAN 输入随机噪声、输出不可控;在输入加**类别条件**得到预期输出。生成网络输入 `z` 加辅助信息 `y`(类别标签/其它模态),判别网络输入 `x` 也加 `y`。P27–28
  - **InfoGAN**:无监督 CGAN,输入=噪声 `z`+隐编码 `c`,无监督学出含语义结构的 `c`,并学出条件分布 `Q(c|x)`。P29

### 自编码器与 VAE(P31–P35)
- **自编码器**:无监督前馈网络,学恒等映射重构输入。编码器把高维输入压成低维隐向量、解码器重构 `x̂=D(z)`。应用:压缩、特征提取、去噪、生成。P31
- **去噪自编码器**:同结构,主要用于数据去噪、特征提取。P32
- ⭐**变分自编码器(VAE)**:编码器把输入映射到一个**概率分布**(而非固定向量),解码器从分布**采样**再还原。隐向量 `z~N(μ_x, σ_x)`。P33
- **目标函数**:重构项 + **KL 散度(相对熵)**(量化两分布差异)。P34
- ◆**重参数化**:从 `N(μ,σ)` 采样 = 在 `N(0,1)` 采 `ε`,再算 `Z=μ+ε×σ`,从而可对 `μ、σ` 求导。**缺点**:生成结果与训练输入类似。P35

### ⭐ 扩散模型(P36–P48)
- **扩散模型/DDPM**:2020 提出,在图像合成上**击败了 GAN**。P36
- ⭐**两个过程(必考)**:
  - **正向扩散过程**:给定 `x_0`,不断在前一时刻图像上加高斯噪声,把数据分布转换为近似标准正态;是马尔可夫链,可推导直接采样获得任意时刻样本。P37–38
  - **反向去噪过程**:对噪声图 `x_T` 逐步去噪还原出接近原分布的 `x_0`;马尔可夫链,据当前时间步和图像采样噪声得到前一时刻图像。P39
- **训练 = 训练噪声预测器**:输入=时刻 `t` 和加噪图像,输出=预测噪声,真值=该步对应噪声。P40
- **噪声预测网络 = 改进 U-Net**:原始 U-Net 是对称全卷积(编码器下采样压缩、解码器上采样还原);改进:卷积块换**残差块**+加**自注意力层**;**时间 t 编码为向量作条件输入**为不同时间步预测噪声。P41–42
- ⭐**文本怎么用**:把文本**作为条件**加在每一次去噪过程中,实现 text2image(如"一只可爱的小猫")。P44

### ⭐ 优化效率里程碑:Stable Diffusion 及衍生(P45–P57)
- ⭐**Stable Diffusion(隐扩散 LDM)**:扩散和逆扩散都在**隐空间**进行,**大大减小显存与计算量**(优化效率的里程碑)。用自编码器编/解码把原图与隐空间互转,如 512×512×3 → 64×64×4。P45
  - **训练**:图 `x` 经编码器得 `z_0` → 随机时间步 `t` 加噪 `ε` 得 `z_t` → U-Net 预测噪声 `ε̂`,反传更新使 `ε̂` 接近 `ε`。**推理**:随机噪声 `z_T` 不断"减去"预测噪声得 `z_0`,再经解码器得 `x`。P46–47
- **Palette**:扩散用于图像翻译(着色、修复、剪裁恢复、解压缩)。P49
- **DALL-E 2**:文本生图。训练三步:①训 CLIP 文/图编码器(文/图→embedding)→②训 prior(文 embedding→图 embedding)→③训 decoder(扩散模型如 GLIDE,用图 embedding 引导生成)。**不足**:直接在图像空间扩散,需级联放大(64→256→1024)、计算资源需求高。P50–53
- **ControlNet**:原始 SD 每种控制条件都要全参更新;核心思想是**克隆扩散模型权重为"可训练副本"与"锁定副本"**,旁路微调可训练副本实现特定输入控制。P54–55
- **DiT(Diffusion Transformer)**:用 **Transformer 替代 U-Net** 做噪声预测;latent 经 patch 化输入级联 DiT,条件(类别)和时间向量化后为每个像素提供控制。P56
- **Sora**:视频压缩网络 + Diffusion Transformer;支持多分辨率提示,生成影视级、时序一致、最长 60s 视频。P57
- **GPT-4o 原生图像生成**:单图含 20+ 对象并保持关系、多轮对话、多风格;**自回归图像生成**(自回归 Transformer 生成 visual tokens → 滚动分组扩散解码,每步对 visual tokens 与 text embedding 做 cross-attention)。P59–62

## 三、视觉-语言模型(多模态)(P63–P73)

- ⭐**VLM 挑战**:模型缺迁移能力、数据获取难。NLP 启发:**BERT 自监督训练**、**GPT 用 prompt 赋予迁移能力**。P65
- ⭐**CLIP(Contrastive Language-Image Pre-training)**:核心训练方法——
  - **打标签→网上搜语料→填空式/对比预训练**:利用互联网获取大规模**图像-文本对**(4亿对)预训练,降低对精确人工标注依赖。P66
  - **双编码器结构**+**自监督对比学习**(batch size 为 N),捕捉图文关联,具强泛化与**零样本(zero-shot)** 能力,甚至超过监督模型。P66–67
  - **推理**:分类标签→文本,做零样本预测(与传统分类模型的区别)。P68
- **BLIP**:统一视觉-语言理解与生成的**混合编码器-解码器**,三类损失:①单模态编码器 ITC(图文对比)②基于图像的文本编码器 ITM(图文匹配)③基于图像的文本解码器 LM(语言建模,使能生成文本)。P69
  - **描述生成过滤(CapFilt)**:Captioner 生成图像描述(LM 损失微调)、Filter 去除不匹配图文对(ITC+ITM 微调)。流程:含噪网络数据预训练→COCO 微调 Cap/Filter→清洗数据→重训。P70–71
- **BLIP-2**:解决对齐难、成本高;**冻结预训练视觉编码器和 LLM,只训轻量 Q-Former** 降成本。两阶段:①冻 ViT 训 Q-Former 学与文本最相关的视觉表征 ②用冻结 LLM 引导视觉→语言生成,实现 zero-shot 图生文。P72–73

## 四、智能体(Agent)系统(P74–P88)

- **智能体定义**:在特定环境中**自主感知、决策、执行动作**以实现目标的实体(自动驾驶、围棋 AI、语音助手、机器人等)。P74
- **两个关键**:"智能"系统(以 LLM/MLLM 等算法为核心)+与"环境"交互(物理/虚拟环境,"人"也可作环境如 ChatGPT)。P75
- ⭐**基于大模型的智能体系统**:**LLM 充当大脑**分解复杂任务、子步骤自主决策;通常还含**规划(planning)、记忆(memory)、工具使用(tool use)** 三大部件。P76
- ⭐**规划(planning)** = 子任务分解 + 反思:
  - **子任务分解**:用 LLM 把大任务拆成可管理子任务,常用 **CoT(思维链)、ToT(思维树)**。P77
  - **反思(self-reflection)**:完善过去决策、纠错迭代改进,常用 **ReAct、Reflexion、Chain of Hindsight**。P78
- ⭐**记忆(memory)**(对照人类):
  - **感知记忆**↔原始输入(文本/图像等)的嵌入表示(视觉/语音编码器);**短期/工作记忆**↔上下文学习的输入(受限上下文窗口,如提示工程);**长期记忆**↔外部向量存储,查询检索利用(如 **RAG**)。P79
- ⭐**工具使用(tool use)**:给 LLM 配外部工具大幅扩展能力(如 ChatGPT 插件/API、函数调用)。代表:**HuggingGPT**(ChatGPT 当任务规划器,选 HuggingFace 模型并归纳结果)。P80
- **动作(Action)**:在环境中执行动作影响环境;规划模块综合**工具反馈+记忆检索的上下文**推理生成动作序列并执行。P81
- **LLM 智能体框架能力**:语言能力(输入输出/推理/上下文学习)、决策能力(规划解复杂问题)、灵活性(推理+记忆+工具→泛化)。P82
- **Manus**:首个通用 AI 智能体,自主执行任务(多模态、高级工具调用、自适应优化)。P83–84
- **MCP(Model Context Protocol)**:解决 M 个应用×N 个工具 = M×N 集成问题,提供标准接口(类似 USB-C)转为 **M+N**;客户端-服务器架构(Hosts/Clients/Servers)。P85–86
- **A2A(Agent2Agent)协议**:解决 Agent 碎片化、难协同;让不同供应商 Agent 互相发现、安全交换信息、协同完成任务(能力发现/任务管理/协作通信/UX 协商)。**A2A 关注智能体间通信("找伙伴"),MCP 关注智能体与环境交互("做事能力")**。P87–88

## 五、⭐ 神经网络量化(P90–P110)

### 为什么量化(P90–P92)
- ⭐**为什么量化**:深度网络规模不断增大,计算/存储成本越来越高;大模型崛起加剧成本(如 GPT-4 1.7万亿参数、2.5万块 A100 训近100天、超1亿美元)。P90
- **什么是量化**:把高位宽数据(FP32/BF16)**离散化**为低位宽数据(INT8/FP8/FP4)做表示和计算。P91
- **优势**:减少计算量、提升速度、降能耗、减存储、减小乘法器面积。P92

### ⭐ 数值量化的类型(P94–P99)
按维度分类(P94、P102):
- ⭐**量化对称性**——
  - ◆**对称量化**:`Q = R / 2^p`,反量化 `R̂ = Q × 2^p`。求参:n 位定点最大绝对值 `A=(2^{n-1}−1)×2^p`,由 `A/2 < Z ≤ A`(`Z=max(|R|)`)得 `p = log₂( Z / (2^{n-1}−1) )`。P95
  - ◆**非对称量化**:数据关于 B 对称,`Q = (R−B) / 2^p`,反量化 `R̂ = Q × 2^p + B`。偏移 `B=(Z_min+Z_max)/2`,`p = log₂( (Z_max−Z_min) / (2(2^{n-1}−1)) )`。P96
- ⭐**量化均匀性**——**均匀量化**:各数据表示间隔相同,拟合灵活性弱但得定点数、计算效率高;**非均匀量化**:拟合效果好但计算效率通常比定点数低。P97
- ⭐**量化粒度**——**分层量化**(每层 W 共享一套参数)、**分通道量化**(每层每通道共享)。相同位宽下粒度越细越能拟合不同通道数据,但访存/计算量更大。P98
  - 大模型更细粒度:分矩阵(粗)→分通道/分词元(token,中)→分组/分块(细)。P99

### 神经网络量化过程(P100–P101)
- **前向传播量化**:激活和权重都量化后再算卷积/全连接,输出再反量化回 FP32。P100
- **反向传播量化**:激活、权重、激活梯度(AG)都量化后算反传,得当前层 AG 和权重梯度(WG)。P101

### ⭐ 优化目标:推理加速(PTQ vs QAT)与训练加速(P103–P106)
- ⭐**训练后量化(PTQ)**:全精度训练得预训练模型后,用小部分**校准数据**统计分布、算量化参数完成量化;**仅前向量化、无需微调/训练**。优势:流程简单、成本低;劣势:拟合有限、低位宽精度低。流程:预训练模型 + 校准数据 → 校准 → 量化 → 量化模型。P103
- ⭐**量化感知训练(QAT)**:对预训练模型量化后**对整个网络微调/再训练**;微调时**前向量化、反向不量化**。优势:低位宽精度更高;劣势:复杂、耗训练资源、成本高。流程:预训练模型 + 训练数据 → 量化 → 再训练/微调 → 量化模型。P104
- **训练加速:量化训练**:从初始化参数**从头训练**全程量化(激活/权重/梯度都量化),不用预训练模型;优势:同时加速训练与推理;劣势:不能用过于复杂的量化方式。P105
- **混合精度量化**:对各层激活/权重/梯度分配不同比特;精度分配粒度:①层级 ②迭代级 ③数据级。P106

### ⭐ 大模型量化(P107–P110)
- **量化对象**:GEMM 计算量化神经元 X 与权值 W;Attention 计算量化 Q、K、V。位宽:Q、X 以 8bit 为主,W、K、V 以 4bit/8bit 为主。P107
- **仅权值量化**:减少权值加载时间与内存占用,适合 IO 瓶颈下 decode 延迟。**GPTQ**(离线校准集、迭代逐块量化权值、最小化量化误差)、**AWQ**(校准集通过激活识别重要权重通道、做通道缩放)。P108
- **神经元和权值量化(SmoothQuant)**:把神经元量化难度**转移给权值**,放缩 W 与 X 对应通道使 X 分布更均匀;适合降 context/decode 延迟。P109
- ⭐**KV 量化(KIVI)**:
  - **为什么出现**:降低内存占用、减少加载 KV Cache 时间,适合长序列与 decode 阶段、提高内存瓶颈下 batch 上限。P110
  - **KV cache 作用/原理**:KV cache 里存放序列长度个 token 的 K/V 数据(避免重复计算历史 token)。KIVI 每 G 个 token 分一组做分通道量化,不足 G 个的暂不量化——更久远历史是低精度、局部相关性高的近期序列保持高精度,达到精度与性能平衡。P110

- 全章主线:适合图像的 CNN → 适合语音/文本的 RNN → 从深度学习到大模型 → 神经网络量化。P111
