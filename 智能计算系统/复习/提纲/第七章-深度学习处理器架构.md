# 第七章 深度学习处理器架构 · 复习提纲

> **老师强调**:本章讲深度学习处理器(DLP)的硬件结构,围绕"计算—访存—通信"三大主线展开。重点掌握——DLP 结构的两大特点(取消传统输入直接用 IO 连外部、增设便笺存储器从机经 DMA 访问外部 DRAM)、DLP 相比通用处理器的优势、运算单元如何由内积单元逐级组合成更大规模(几个组件拼一个、多组件嵌套扩规模),以及矩阵单元/脉动阵列/向量标量单元/分离式便笺/软件流水线/通信拓扑的设计思路。会算计算-I/O 比例、会画运算单元组合与脉动阵列数据流。
> **页码均指 PDF 页(共150页)。⭐=老师明确点名考点,◆=必会计算/会画。**

---

## 一、总体架构与 DLP 结构特点(P2,P102,P131)
- **三大主线**:总体架构 = **计算 + 访存 + 通信**,全章按此三块组织。P2
- ⭐**DLP 结构两大特点**(对比通用处理器,与第六章承接):
  1. **取消传统输入**,直接用 **IO 连接外部**(不走通用处理器那套外设输入通路)。
  2. 增设**便笺存储器(scratchpad memory)从机**(如 NRAM/WRAM),直接用 **DMA** 访问外部 DRAM,而非依赖 Cache 层次。P104,P122
- ⭐**DLP 的优势**:工作在便笺存储器上 → **一条 load 装载整块图像、一条指令完成计算、一条 store 送回内存**;通用处理器处理 224×224×3 图像需约 **30 万条 load/store**,DLP 仅需极少指令,访存与控制开销大幅下降。P120–121

## 二、计算:三种计算单元(P3–P5)
- **三种计算单元**:**矩阵、向量、标量**,常见架构(TPUv4i、Cambricon、Volta、"达芬奇")中**三者共存、各司其职**。P3–5

## 三、矩阵运算单元——逐级组合(P6–P19)
- ◆**核心计算指标:计算-I/O 比例**——比例越高(I/O 占比越小)越好,贯穿全节的优化目标。P6
- **从乘法器到内积单元**(逐步堆叠,比例逐步改善):
  - 单乘法器 `1:3` → 向量乘法器 `1:3` → 向量内积单元(加 `+`)`3:5=1:1.6` → 更宽内积 `7:9=1:1.3`。P6–9
- ⭐◆**逐级组合规律**(老师点名:几个组件拼一个、多组件嵌套扩规模):
  - **多个内积单元 → 矩阵乘向量单元**(`1:1.3`)。P10
  - **近端存权值**:权值存内积单元附近的小而快存储器(局部权值存储)→ `7:5=1:0.7`。P11
  - **广播激活值**:所有内积单元共享激活值(广播)→ `7:3=1:0.4`。P12–13
  - **增加内积单元数量**→ `7:2=1:0.3`;**提出权值** → `28:24=1:0.9`。P14–15
  - **增加一组矩阵乘向量单元** → `1:0.9`;**广播共享权值 → 矩阵乘矩阵单元** → `56:32=1:0.6`;**扩大规模** → `112:48=1:0.4`。P16–18
- ⭐**矩阵乘向量 vs 矩阵乘矩阵**:矩阵乘向量计算密度已较好(`1:0.4`);矩阵乘矩阵规模大时理论更优(第六章),但**连线复杂、距离远、扇出多**,规模不大时无实际优势(`1:0.3`)。P19

## 四、矩阵运算的执行过程(P20–P33)
- ◆**会画/会推**:以 `[[a,b],[c,d]]×[[v,x],[y,z]]` 为例,展示数据如何逐拍喂入向量内积单元/矩阵乘矩阵单元并得到 `[[av+bx, ay+bz],[cv+dx, cy+dz]]`。P20–32
- **矩阵乘矩阵单元**:多内积单元并排,激活值与权值分别送入,比例可达 `1:1`。P29–32
- **遗留问题**:连线距离远、扇出多 → 引出脉动阵列。P33

## 五、脉动阵列机(systolic array)(P34–P52)
- ◆**会画数据流**:激活值与权值从两个方向"脉动"流入二维阵列,每个 PE 做乘加并向邻居传递,数据逐拍对齐相遇,最终算出矩阵乘结果;**计算-I/O 比例 `1:0.75`**(示例 4×4)。P34–49
- ⭐**脉动阵列 vs 矩阵乘矩阵单元**:
  - **优势**:计算-I/O 比例更高(`1:0.2` vs `1:0.4`)、电路**局部短连接**、**扇出少**。
  - **困难**:延迟高(需等待**启动/排空**);**专用性更强**,高效支持矩阵乘与卷积,但难改造支持其他功能。P51
- **历史**:雏形见于二战英国 Colossus Mark II(1944,破译德军密文);孔祥重与 Charles E. Leiserson 于 1978 年发明,多种结构对应矩乘/解线性方程组/LU 分解/求 GCD 等。P52

## 六、向量与标量运算单元(P53–P101)
- **主要功能**:池化、归一化;Dropout/ReLU/Sigmoid/Softmax 等特殊变换;求最大/最小、排序、计数、前缀求和;数据重排布。结构 = 便笺存储器 + 寄存器堆 + 运算单元。P53

### 池化 / 归一化(P54–P70)
- ◆**池化实现**:数据从便笺逐列流入,用**累加寄存器**逐步累加(或取 max),示例 2×2 平均池化得 `1.5/5.5/9.5/13.5`。P54–63
- **运算单元结构**:加法器 + MUX(选累加或直通)+ 乘 `1/4` → 支持 **AvgPool**;扩展后**一组硬件同时支持 AvgPool、MaxPool、BatchNorm**(`+/max` 可选、`γx+β`)。P64–70

### 激活函数(P71–P79)
- ◆**tanh 分段线性近似**:`tanh(x)=(eˣ−e⁻ˣ)/(eˣ+e⁻ˣ)`;用**最小二乘法**定分段系数 `A[i]、B[i]`,`i=⌊x÷0.5⌋`(不超过 5),`tanh⁺(x)=ax+b`,负区用奇对称 `tanh(x)=−tanh⁺(−x)`(x<0)。硬件:abs、÷0.5、max5、查表取 a/b、乘加、符号还原。P71–76
- **精确计算特殊函数**:推理任务下分段线性插值基本够用;需精确时用**快速数值算法**(如 Beame-Cook-Hoover 快速倒数)、**数值方法**(牛顿迭代),或二者结合(如 `0x5f3759df` + 牛顿迭代)。P77–79

### 前缀计算(P80–P91)
- **定义**:`y0=x0, y1=x0⊙x1, y2=x0⊙x1⊙x2, …`,是重要并行模式;可做前缀求和、横向求和/平均/最大、非零计数等。P80
- ◆**高效并行结构**:递归构造 `Pₙ`——偶数线直通、奇数线接入 `P_{n/2}`,树形归约 + 回填,复杂度低于朴素串行。P81–91

### 数据重排布(P92–P100)
- **动机**:以向量为单位、便笺访问对齐,向量内不同位置数据难"相遇"(如算 `4a+5c+6b+7d` 需先换 b、c)。可用标量指令编程交换,但**增设向量重排列功能更高效**。P92–96
- ◆**排列网络**:`P2` 开关(直通/交换);递归构成 **Beneš 网络**(奇/偶线分别接 `P_{n/2}`)、**Waksman 网络**(省去首个开关)。P97–100

### 计算小结(P101)
- 矩阵单元可设计为矩阵乘向量/矩阵乘矩阵/脉动阵列,各有优势区间;向量/标量单元增设累加寄存器实现池化、一组硬件支持多功能、分段线性近似算特殊函数、增设前缀计算与重排布拓展通用性。P101

## 七、访存:便笺存储器(P103–P118)
- **便笺存储器**:多用 **SRAM** 实现,是 DLP 核内数据"**枢纽**",连接矩阵单元(2R,1W)、向量单元(2R,1W)、标量寄存器(1RW)、DMA/外存/其他核(1RW)。P104–107
- **缓解访问拥堵两条思路**:**拓宽道路** + **规划车流**。P108
- ⭐**拓宽道路**:
  - **多端口 SRAM**:每加一端口面积 +50%~100%(面积=成本、能耗、延时)。P109
  - **分组 SRAM(bank)**:开关阵列面积 ~O(分组数²),存在**分组冲突(bank conflict)**。P110
- ⭐**规划车流(分离式便笺存储器)**:类比通用处理器用**哈佛结构**解取指-取数冲突,DLP 用**分离式便笺**(二/三分离)。划分方式:
  - **按数据**:神经元/权值,或输入神经元/输出神经元/权值。P113–114
  - **按功能单元**:向量/标量,或矩阵/向量/标量。P115
  - **按处理阶段**:输入数据/累加器。P116
- **权衡**:分流提升效率,但约束使用方式、**损失通用性**;体系结构设计者的职责是**找一组高效合理的约束**。P117–118

## 八、访存:外部存储器访问与软件流水线(P119–P130)
- **访存时长对比**:通用处理器 load/store 持续数个周期;DLP 经 DMA 访外存持续 **100~100000 周期**。P119,P123
- ⭐**DMA**:实现"一条 load 装整块图像"——处理器只发 `load r~b`,由 DMA 控制成块搬运(便笺 ↔ 主存)。P122
- ◆**软件流水线**:把 load/compute/store 在 **DMA 模块**与 **EX 模块**上交叠执行 → 计算与访存并行;由**编译器或程序员重排指令**(无需乱序执行),用 **显式 sync 同步**(无需依赖检查),从而**简化硬件**。P124–127
- **sync 实现**:计算模块/DMA 模块随时执行收到的指令;指令发射模块按类型分发(计算→EX、访存→DMA),遇 **sync 阻塞**直到整个处理器空闲再发新指令。P128–129
- **访存小结**:便笺是数据枢纽,可能成瓶颈;拓宽道路(加端口/分组)代价是硬件开销,规划车流(分离式)代价是通用性;用软件流水线 + 显式同步替代硬件乱序与依赖检查。P130

## 九、通信:多核多卡扩展(P132–P139)
- **任务划分模式**:**数据并行**(全局归约 all-reduce)、**模型并行**、**算子内并行**(全局交换 all-to-all)、**算子间并行**(局部通信);实际常**混合使用**。P132–133,P136–137
- ⭐**全局归约(all-reduce)**:通过一个**环(ring)** 即可高效实现;但这**不意味着**多核 DLP 物理上必须设计成环。P134–135
- **物理链路设计**:
  - **总线(bus)**:AXI、PCI-E 等标准,性能差、成本低。
  - **片上网络(NoC)**:胖树、二维环面等拓扑,性能较好、成本可控。
  - **交叉开关(crossbar)**:性能最佳、成本高。P138
- **通信小结(设计原则)**:逻辑上环状链路足够;物理上适当增加冗余、按需配成环;综合性能与成本取舍。P139

## 十、优化设计:变换 / 压缩 / 近似 / 非传统器件(P140–P148)
- **四大方向**:**变换**(削减计算强度)、**压缩**(减参数量与计算量)、**近似**(降计算成本)、**非传统结构与器件**(改写计算范式)。P140
- **变换**:快速矩阵乘(Strassen、Coppersmith-Winograd、FFT)、快速卷积(Winograd 最小滤波)、**算子融合**(串行算子融合,减访存)。P141
- **压缩**:**网络裁剪**(零值不算,加硬件选非零)、**结构化稀疏**(让非零规律分布,简化选数)、**串行计算**(逐比特跳 0)。P142
- **近似**:**数值量化**(INT4/FP4/BFP/PoT/BNN/可变精度,低精度近似+误差校正)、**算法近似**(低秩分解、差分计算)、**随机计算**(随机比特串,加法器→MUX、乘法器→与门)。P143–145
- **非传统器件**:**存内计算(PIM)** 在内存内完成计算;**神经拟态计算**(ReRAM/CBRAM/PCM 驱动,激活值→电压、权值→电导、输出→电流,计算发生在权值存储矩阵内)。P146–148

## 十一、全章总结(P149)
- **计算**:矩阵/向量/标量各司其职,多种实现方式各有优势区间。
- **访存**:"拓宽道路、规划车流",合理利用应用特性。
- **通信**:高效完成全局归约/全局交换,逻辑链路简单、物理链路灵活。
- 概览了变换/压缩/近似/非传统器件等常见与前沿优化。P149
