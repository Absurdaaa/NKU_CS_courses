## 一、为什么需要 CNN(P10–P12)
- **全连接的参数爆炸**:32×32×3=3072 输入、100 隐层神经元 → 第一层权重 307200;1024×1024 输入+1000 神经元 → 权重达 10⁹,过多参数导致过拟合。P10–11
- **CNN 两大法宝**:**局部连接**(神经元只连接局部区域)+**权重共享**(输出层共用一组权重),大幅减少权重数量,避免过拟合,为加深网络提供可能。P12,P24
  - 全连接权重量 `wᵢ×hᵢ×wₒ×hₒ`,卷积权重量仅 `f×f`(单核)。P12

## 二、CNN 总体结构(P13,P29–P30)
- **组成**:卷积层(conv)+池化层(max pool)+全连接层(FC)+Softmax;以 **VGG16** 为典型例(conv1–conv5 五段,输出 224→112→56→28→14→7)。P13
- **特征提取器 vs 分类器**:卷积层+池化层=特征提取器;全连接层=分类器。P29
- ⭐**层排列规律**:`input →(Conv+ReLU)×N →pool` 重复 M 次 →`(FC+ReLU)×P →FC/softmax`。例 N=3,M=1,P=2:`input→conv ReLU→conv ReLU→conv ReLU→pool→FC(ReLU)→FC ReLU→FC→output`。N/M/P 为重复次数。P30

## 三、卷积层(核心)(P14–P26)
### ⭐◆ 卷积运算:怎么算 + 与数学卷积的区别 P15–P22
- **数学卷积**:`yₙ = Σᵢ xᵢ·h(n−i) = x(n)∗h(n)`,核要先翻转再滑动。P15
- **神经网络中的"卷积"**:实际是**矩阵内积**(对应元素相乘再相加,核**不翻转**)——这是与数学卷积的关键区别。P15
- ◆**单输出特征图**:核在输入上滑动,每个位置做相乘求和得一个输出值。讲义 P15–16 有 2D 数值例(结果 32、40、37…),要会一步步算。P15–16
- ◆**多输入单输出**:输入 6×6×3、核 3×3×3 → 输出 4×4;三个通道分别卷积后**逐通道相加**(P18 例:2+0+(-1)=…=2)。P17–19
- **多输入多输出**:输入 6×6×3、2 个 3×3×3 核 → 输出 4×4×2;不同滤波器检测不同特征。P20
- **特征含义**:核即 filter/kernel,权重作为参数在训练中学习;可检测水平/垂直/对角边缘等(P22 给出垂直边缘、对角线边缘的检测例)。P14,P22
- **卷积≈矩阵相乘**:相乘再相加可转为向量内积,多通道卷积可整体转为矩阵乘法。P21

### ◆ padding 与 stride、特征图尺寸计算(必考)P23,P25
- **padding(边界扩充)**:扩大输入并填充像素,作用——防止深层网络特征图持续缩小、强化边缘信息。P23
- **stride(步长)**:卷积窗口每次滑动的像素数;与 pad 共同决定输出尺寸。P23
- ◆**输出特征图公式(必背会算)**:`Wₒ = ⌊(Wᵢ+2p−K)/s⌋+1`,`Hₒ = ⌊(Hᵢ+2p−K)/s⌋+1`。例:输入 5×5、核 3×3、p=1、s=2。卷积核尺寸可为 3×3、1×3、3×1 等,代入同一公式即可。P23,P25
- ⭐**理解而非死记**:padding 补够则尺寸不变(SAME),stride>1 则尺寸成比例缩小。

### ◆ 卷积层参数与计算量 P25–P26
- **参数量**:权重 `Cₒ×K×K×Cᵢ` + bias `1×1×Cₒ`;核与 bias 均可训练,bias 使分类器偏离激活原点更灵活。P25
- ◆**计算量**:`Wₒ×Hₒ×Cₒ×Cᵢ×K×K`。P25
- **深度可分离卷积**:参数量 `K×K×Cᵢ + Cᵢ×Cₒ`,计算量 `Wᵢ×Hᵢ×K×K×Cᵢ + Wₒ×Hₒ×Cᵢ×Cₒ`,显著少于普通卷积(用于轻量化网络)。P26

## 四、池化层 / 全连接层 / Softmax(P27–P28)
- ◆**池化(Pooling)**:Max/Avg/L2;主动缩小特征图→减少参数与计算量、控过拟合,**不引入额外参数**。例:filter 2×2、pad 0、stride 2,Max pooling 保留最大值提高鲁棒性。P27
- **全连接层(FC)**:把高维特征图映射成一维特征向量(含全部特征),再转为各类别概率。P28
- **Softmax**:网络最后一层,归一化输出分类概率,凸显最大值、抑制其余;输入输出规模相同。`f(zⱼ)=e^{zⱼ}/Σᵢe^{zᵢ}`。P28

## 五、为何"深"而非"广"(P31–P32)
- **可视化**:浅层学局部特征,深层学整体特征(感受野由小到大)。P31
- ⭐**深层的两大好处**:① 从局部到整体"理解图像"(浅层感受野小→局部,深层感受野大→整体);② **减少权重数量**——用多个小卷积替代一个大卷积,特征更多样、权重更少。即使单隐层理论上能拟合任意连续函数,深层仍更优。P32

## 六、参数初始化(P34–P39)
- **随机初始化**:均匀分布 `U(−a,a)` 或正态分布 `N(0,σ²)`(例 DeepSeek-V3 σ=0.006)。P34
- **Xavier 初始化**:满足 **Glorot 条件**(前向各层输入方差一致、反向各层梯度方差一致),`Var(Wᵢ)=2/(nᵢ+nᵢ₊₁)`;适用于关于 0 对称、原点单位导数的激活(如 tanh)。P35–37
- **Kaiming 初始化**:针对 ReLU/PReLU 等非对称激活改进,`Var(Wᵢ)=2/nᵢ`;CV 任务常用。P38–39

## 七、⭐ 梯度下降法与优化器(P40–P52)
### ⭐ 梯度下降原理 + ◆ mini-batch 特性 P40–P41
- ⭐**原理(必懂为什么)**:损失函数关于参数 w 的**负梯度方向是下降最快方向**,故沿负梯度更新即可找到使 L 最小的参数。`w ← w − η·∇_w L(w)`。P40
- **三种 GD 对比**:**GD** 用全部样本(复杂度高);**SGD** 随机抽一个样本(随机性过大、效率低);**mini-batch SGD** 抽一个 batch(复杂度低、效率高)`w ← w − (η/p)·∇_w Σᵢ Lᵢ(w)`。P40
- ⭐**mini-batch SGD(深度学习默认的 SGD)**:每次迭代取一个 mini-batch 算梯度更新;**加速特性**——兼顾计算复杂度与优化效率。缺点:学习率难选、易陷局部最优/鞍点。`gₜ=(1/p)∇_w ΣᵢLᵢ(wₜ)`,`wₜ₊₁=wₜ−η·gₜ`。P41

### 其余优化器(知道各自解决的问题)P42–P52
- **Momentum(动量)**:积累历史梯度抑制震荡、加快收敛。`vₜ=μvₜ₋₁−ηgₜ`,`wₜ₊₁=wₜ+vₜ`。P42
- **NAG**:先用速度更新临时参数再算梯度,方向更稳、进一步减震荡。P43
- **二阶方法**:**牛顿法**用 Hessian 逆 `θ*=θ₀−H⁻¹∇f` 收敛快但存储贵;**BFGS** 近似 Hessian 逆(O(n²));**L-BFGS** 只存历史差值(O(n))。P44–45
- **AdaGrad**:逐参数除以历史梯度平方和的平方根→各参数不同学习率;稀疏梯度好,但后期学习率过快缩小。P47
- **AdaDelta / RMSProp**:AdaGrad 改进,用衰减系数限制历史梯度窗口,缓解学习率快速衰减;RMSProp 常用于 RNN。P48–49
- **Adam**:带动量的 RMSProp,用一/二阶矩估计动态调学习率,兼具 AdaGrad/RMSProp 优点,训练稳、收敛快。P50
- **AdamW**:权重衰减与梯度更新**解耦**,防过拟合;BERT/GPT/Llama/DeepSeek 等大模型常用。P51

## 八、⭐ 应用于图像分类的典型网络(发展脉络)(P53–P85)
> ⭐**脉络主线**(每个网络解决前一个的问题):neocognitron(雏形)→ LeNet(1998 手写识别)→ **AlexNet(2012)→ VGG → Inception → ResNet → DenseNet/SENet**。能据问题画大致框图即可,不要求逐层标参数。P53–54

- **AlexNet(2012,ILSVRC 冠军,top5 15.3%)**:首次用深 CNN 解图像分类。创新:**ReLU**(收敛快)、**Dropout**(随机丢神经元抗过拟合)、**LRN**(局部响应归一化,后被证无明显效果)、**MaxPool**、数据增强。➡ 解决"如何用 CNN 大规模分类"。**遗留问题:更多卷积层能否更好?** P55–59
- ⭐**VGG(2015,top5 7.5%)**:规整 `3×3 conv(s=1,pad=SAME)+2×2 maxpool(s=2)` 堆叠;卷积层管深度(特征图数量)、池化层管长宽(尺寸)。➡ 解决"网络能否更深"。P60–61,P66
  - **多层小卷积 > 单层大卷积**:两个 3×3 与一个 5×5 感受野相同,但权重更少(7×7=49 → 三个3×3=3×3×3=27)、非线性更强、准确率更高。P62–63
  - **由简到繁训练**:先训 VGG11(A),再用其权重初始化更深网络。P64–65
  - **遗留问题:卷积核还能更小吗?网络还能更深吗?**
- ⭐**Inception 系列(GoogLeNet)**:➡ 解决"如何在不暴增计算量下变宽变深"。P67–77
  - **Inception 模块**:并联多尺寸卷积+池化获多尺度特征(naïve);用 **1×1 卷积**做"瓶颈层"降维减参。P68
  - ◆**1×1 卷积**:跨通道全连接,co<ci 时降维减参。例 5×5 直连乘加 4.8×10⁸ → 先 1×1 降到 32 通道,乘加降至 6.7×10⁷。P69–70
  - **Softmax 辅助分类器**:训练时中间层加 softmax 按小权重并入,防梯度消失(模型融合);推理时去掉。P72
  - **BN-Inception**:每个卷积后、激活前插 **BatchNorm**(归一到标准正态→避免梯度消失、加快训练、可用更大学习率,可替代 LRN/Dropout);并学 VGG 用两个 3×3 代 5×5。P73–75
  - **Inception-v3**:把 3×3 拆成 1×3 与 3×1(**Factorization**),减参且增特征多样性;7×7 拆成 3×3。P76–77
- ⭐**ResNet(2016 best paper,top5 3.57%)**:➡ 解决 VGG 加深后的**网络退化**问题。P78–82
  - **退化≠梯度消失/过拟合**:深层训练误差反而更高,是收敛到极值而非最值。BN 已能缓解梯度消失。P79
  - **残差**:普通网络拟合输出,残差网络拟合**差值 output−input**(加 shortcut),对波动更敏感、更易学到最优、更易收敛。P80–81
  - **改造规则**:全 3×3(s=1,pad=SAME);尺寸减半由 s=2 卷积完成;尺寸不变则特征数不变,**尺寸减半则特征数翻倍**(实线直连,虚线降采样)。翻倍两法:补 0(不引入参数)/ 1×1 卷积映射(引入参数)。P82
- **残差思想的延伸**:**DenseNet**(块内每层连接之前所有层,通道拼接,促进特征/梯度复用)、**SENet**(Squeeze 全局平均池化→Excitation 经 MLP 生成逐通道权重,注意力机制雏形);残差连接也用于 Transformer。P83–84,P132–135
- **图像分类算法全景**:CNN(AlexNet/VGG/网络中的网络/Inception/ResNet/DenseNet/SENet/MobileNet/EfficientNet)、Transformer(ViT/Swin/DeiT)、多模态(CLIP)、MLP-Mixer。P85

## 九、应用于目标检测的卷积神经网络(P86–P131)
> 本节为目标检测,按 PPT 顺序记其评测指标与算法脉络(老师点名的检测细节可能在后续 part 展开,这里保留主线)。

- **三类任务**:分类(单大目标,输出 label,评 accuracy)、定位+分类(输出 label+bbox,评 **IoU**)、目标检测(多小目标,多 label+bbox,评 **mAP**)。P86
- ◆**IoU(交并比)**:衡量定位准度,一般 IoU≥0.5 算定位成功。P87
- ◆**mAP(平均精度均值)**:综合 recall 与 precision。`Recall=k/M=TP/(TP+FN)`,`Precision=k/N=TP/(TP+FP)`;阈值越小选中越多→召回升、查准降。AP=对每个 recall 取最大 precision 求平均(VOC2012),例算 AP≈0.1819。讲义 P91–94 有完整算例,要会算。P88–94
- **两类检测算法**:**两阶段**(先生成候选框再 CNN 分类,R-CNN 系列)、**一阶段**(直接输出定位+类别,YOLO/SSD)。P95
- **R-CNN 系列脉络**(逐步统一到一个网络、提速):P96–110
  - **R-CNN**:Selective Search 提 ~2000 候选区→裁剪缩放→AlexNet 提特征→SVM 分类+边界框回归+NMS。慢(53s),重复计算多、多步骤分开训。P97–102
  - **Fast R-CNN**:整图一次卷积+**ROI Pooling**(任意尺寸 ROI→固定尺寸,复用特征)+softmax 代 SVM+回归并入网络。2s。瓶颈仍是 Selective Search。P103–105
  - **Faster R-CNN = RPN + Fast R-CNN**:用 **RPN**(Anchor 机制,3×3 卷积→两路 1×1:softmax 判前/背景 + bbox 回归→NMS)生成候选区,与检测网共享特征。0.2s。**anchor**:每位置 9 个(3 尺度×3 长宽比)。P106–110
- **YOLO 系列(一阶段)**:P111–131
  - **YOLO v1**:目标检测=单回归问题,图分 S×S 格,每格预测 B 个 bbox(x,y,w,h,confidence)+C 类条件概率,输出 `S×S×(B×5+C)`(VOC:7×7×30)。基于 GoogLeNet,Leaky ReLU,45 FPS。优点:快、背景误判少、泛化好;缺点:邻近物体精度低、损失函数过简、训练难收敛。P111–115
  - **演化(各版解决的问题)**:v2 Darknet-19+anchor;v3 残差+FPN 多尺度;v4 PAN+CSP;v5 CIoU 损失+FPN/PAN;X 解耦检测头;v6 量化/蒸馏;v7 ELAN;v8 C2F;v9 PGI;v10 一对一检测头+PSA。P128–131
  - **FPN(特征金字塔)**:Backbone 自下而上生成多尺度特征,再自上而下融合高层语义,提升小/中目标检测。P118–119
- **SSD**:一阶段,结合 anchor-box 与多尺度特征图(大图检小目标、小图检大目标),每点 6 个 default box,速度快且较准。P122–125
- **目标检测算法全景**:Two-stage(R-CNN/SPP-Net/Fast/Faster/FPN/Mask R-CNN…)、One-stage(YOLO 系/SSD 系/RetinaNet/EfficientDet)。P126
