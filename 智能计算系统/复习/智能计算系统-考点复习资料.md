## 0. 考前优先级

### 第一优先级：必会算

1. 卷积/池化输出尺寸：  
   `W_o = floor((W_i + 2p - K_w) / s) + 1`，`H_o = floor((H_i + 2p - K_h) / s) + 1`。  
   非方形卷积核如 `1x3`、`3x1` 分别代入宽、高公式。

2. 网络参数量：  
   全连接层参数量 = `输入数 x 输出数 + 输出数偏置`。  
   卷积层参数量 = `C_o x K_h x K_w x C_i + C_o`。

3. 反向传播链式求导：  
   `∂L/∂w = ∂L/∂ŷ · ∂ŷ/∂z · ∂z/∂w`，然后 `w <- w - η∂L/∂w`。

4. IoU / Precision / Recall / mAP：  
   `IoU = 交集面积 / 并集面积`；  
   `Precision = TP / (TP + FP)`；  
   `Recall = TP / (TP + FN)`。

5. 缩放点积注意力：  
   `Attention(Q,K,V)=softmax(QK^T / sqrt(d_k) + Mask)V`。

6. 广播机制：  
   从末尾维度对齐；每一维必须相同，或其中一个为 1，或其中一个缺失；否则报错。

7. 集合通信原语选择：  
   参数广播用 Broadcast，梯度平均常用 All-Reduce，收集数据用 Gather/All-Gather，归约后切分用 Reduce-Scatter。

8. 编译优化分类：  
   图级优化看数据流和算子关系；算子级优化看底层循环、tiling、vectorize、unroll、SIMD。

### 第二优先级：必会答概念

- 深度学习基础：激活函数、损失函数、过拟合/泛化/正则化、交叉验证。
- CNN：局部连接、权重共享、padding/stride、AlexNet 到 ResNet 的发展脉络。
- NLP/大模型：token、embedding、位置编码、RNN/LSTM/GRU、Seq2Seq、注意力、Transformer、BERT/GPT 区别、Decoder-only 主流原因。
- 生成与多模态：GAN、VAE、扩散模型、Stable Diffusion、CLIP/BLIP、Agent 三部件、量化。
- 框架：Tensor、计算图、自动微分、静态图/动态图、分布式训练。
- DLP：矩阵运算单元、脉动阵列、便笺存储器、DMA、多核/分形扩展。
- 大模型系统：计算优化、存储优化、稳定性优化，重点 ZeRO 与 checkpoint。

## 2. 第二章 深度学习基础

### 2.1 梯度下降

梯度表示函数上升最快方向，因此负梯度方向是损失下降最快方向。参数更新：

```text
w <- w - η · ∂L/∂w
```

η 是学习率。太大可能震荡或发散，太小收敛慢。

### 2.2 参数量计算

全连接层：

```text
参数量 = 输入神经元数 x 输出神经元数 + 输出神经元数
```

最后一项是偏置。考试给网络结构时逐层相加即可。

### 2.3 Batch / Iteration / Epoch

- Batch：一次更新使用的数据量。
- Iteration：用一个 batch 完成一次参数更新。
- Epoch：全部训练数据完整训练一遍。

如果训练集有 `N` 个样本，batch size 为 `B`，每个 epoch 约有 `N/B` 次 iteration。

### 2.4 激活函数

| 函数 | 形式/特点 | 优点 | 缺点/适用 |
|---|---|---|---|
| sigmoid | 输出 `(0,1)` | 可解释为概率 | 非 0 均值、指数慢、饱和区梯度消失 |
| tanh | 输出 `(-1,1)` | 0 均值 | 仍有梯度消失 |
| ReLU | `max(0,x)` | 正区梯度不衰减，训练快 | 负区梯度 0，可能 ReLU 死亡 |
| Leaky/PReLU | 负区保留小斜率 | 缓解 ReLU 死亡 | PReLU 的负区斜率可训练 |
| ELU | 负区指数平滑 | 均值接近 0，收敛快 | 指数计算开销 |
| GELU | `x` 按概率门控 | 平滑，BERT/GPT/T5 常用 | 计算较复杂 |
| SiLU/Swish | `x·sigmoid(x)` | 平滑、泛化好 | LLaMA/DeepSeek 常用 SwiGLU 变体 |

一句话背法：sigmoid/tanh 容易饱和；ReLU 快但会死；Leaky/ELU 修负区；GELU/SiLU 是 Transformer/大模型常用平滑激活。

### 2.5 损失函数

#### MSE

```text
L = 1/2 (y - ŷ)^2
```

若输出层配 sigmoid，梯度中含 `σ'(z)`，当输出接近 0 或 1 时梯度变小，更新慢。

#### 交叉熵

二分类：

```text
L = -[y ln ŷ + (1-y) ln(1-ŷ)]
```

与 sigmoid 配合时，反向传播中 sigmoid 导数项会被抵消，能缓解 MSE + sigmoid 更新慢的问题。

### 2.6 欠拟合、过拟合、泛化

- 欠拟合：模型太简单，训练集都学不好，训练误差大。
- 过拟合：模型太复杂，训练集表现好，但测试集表现差。
- 泛化：模型对未见样本/新场景的适应能力。

### 2.7 防过拟合手段

必须能立刻答：

1. 参数范数惩罚：L1/L2 正则化。
2. 稀疏化：让大量权重或神经元为 0。
3. Bagging：训练多个模型求平均，降低方差。
4. Dropout：训练时随机丢弃神经元，相当于子网络集成。
5. 提前终止：验证误差回升前停止训练。
6. 数据增强：扩大训练数据多样性。

根本思路：增加数据，或降低模型复杂度。

### 2.8 L1 与 L2 正则

- L2：惩罚 `1/2 ||w||^2`，使权重整体变小，也叫权重衰减。
- L1：惩罚 `Σ|w_i|`，更容易把权重推到 0，产生稀疏性。

### 2.9 BN 与 LN

- BN：对一个 batch 的同一维特征归一化，常用于 CNN/CV。
- LN：对单个样本内部的 embedding 维度归一化，常用于 RNN/Transformer/NLP。

### 2.10 交叉验证

- 留一验证：每次留 1 个样本测试，训练 `n` 个模型。优点是充分利用数据，缺点是计算量巨大。
- K 折交叉验证：分成 K 份，轮流 1 份测试、K-1 份训练。留一是 `K=n` 的特例。
- 深度学习大数据场景通常不用 K 折；医学、遥感等小数据场景常用。

## 3. 第三章 深度学习应用

## 3.1 CNN 基础

### 为什么 CNN 能减少参数

全连接对图像像素全连接，参数爆炸。CNN 用：

- 局部连接：每个神经元只看局部区域。
- 权重共享：同一个卷积核在整张图上滑动复用。

这两点显著降低参数量并缓解过拟合。

### CNN 总体结构

典型结构：

```text
Input -> (Conv + ReLU) x N -> Pool
      -> ... 重复
      -> FC -> Softmax
```

卷积/池化层是特征提取器，全连接层是分类器。

### 给定问题设计 CNN 框图

老师强调不要求逐层精确背参数，但要能根据任务画出“大致网络框图”。答题时按这个思路组织：

1. 图像分类：`Input -> 多组 Conv/ReLU/Pool -> Flatten/GlobalAvgPool -> FC -> Softmax`。
2. 目标检测：`Backbone 特征提取 -> 多尺度特征/候选框或检测头 -> 分类分支 + bbox 回归分支`。
3. 需要加深网络时：优先想到 VGG 式小卷积堆叠或 ResNet 残差块。
4. 需要降低计算量时：想到 `1x1` 瓶颈、深度可分离卷积、多尺度共享特征。
5. 输出层按任务选：分类用 Softmax/交叉熵；检测要输出类别、置信度和 bbox。

### 神经网络中的卷积与数学卷积区别

数学卷积需要先翻转卷积核再滑动；神经网络中的“卷积”实际是互相关/矩阵内积，不翻转卷积核。

### 多通道卷积

输入 `H x W x C_i`，卷积核 `K_h x K_w x C_i`。每个输入通道分别做卷积后逐通道相加，得到一个输出特征图。若有 `C_o` 个卷积核，则输出通道数为 `C_o`。

### 输出尺寸公式

```text
W_o = floor((W_i + 2p_w - K_w) / s_w) + 1
H_o = floor((H_i + 2p_h - K_h) / s_h) + 1
```

padding 用来补边，避免特征图过快缩小并保留边缘信息；stride 控制滑动步长，步长越大输出越小。

### 卷积参数量与计算量

```text
参数量 = C_o x K_h x K_w x C_i + C_o
计算量 = W_o x H_o x C_o x C_i x K_h x K_w
```

### 池化

池化主动缩小特征图，减少计算量和过拟合，不引入可训练参数。常见 MaxPool、AvgPool。MaxPool 取局部最大值，提升局部平移鲁棒性。

## 3.2 图像分类网络发展脉络

| 网络 | 解决的问题 | 关键点 |
|---|---|---|
| AlexNet | 证明深 CNN 可用于大规模图像分类 | ReLU、Dropout、MaxPool、数据增强 |
| VGG | 网络能否更深、更规整 | 大量堆叠 `3x3` 卷积，小卷积替代大卷积 |
| Inception | 如何在不暴涨计算下变宽变深 | 多分支卷积，`1x1` 瓶颈降维 |
| ResNet | 深层网络退化问题 | 残差连接，学习 `F(x)=H(x)-x` |
| DenseNet/SENet | 特征复用/通道注意力 | Dense 连接、Squeeze-Excitation |

### VGG：多层小卷积替代大卷积

两个 `3x3` 卷积感受野相当于一个 `5x5`，三个 `3x3` 约等于一个 `7x7`。优点是参数更少、非线性更多、表达能力更强。

### Inception：1x1 卷积作用

`1x1` 卷积做跨通道线性组合。当输出通道数小于输入通道数时，可以降维减参，也可增加非线性。

### ResNet：退化问题

退化不是过拟合，也不完全是梯度消失，而是网络更深后训练误差反而更高。残差连接让网络学习输入与输出的差值，更容易优化。

## 3.3 优化器

| 方法 | 核心思想 | 解决问题 |
|---|---|---|
| GD | 全量样本算梯度 | 稳但慢 |
| SGD | 单样本算梯度 | 快但噪声大 |
| Mini-batch SGD | 小批量算梯度 | 深度学习默认折中 |
| Momentum | 累积历史梯度 | 减震荡、加速 |
| AdaGrad | 每个参数自适应学习率 | 稀疏梯度好，后期学习率过小 |
| RMSProp | 衰减平均梯度平方 | 缓解 AdaGrad 学习率衰减 |
| Adam | Momentum + RMSProp | 稳定、收敛快 |
| AdamW | 权重衰减与梯度更新解耦 | 大模型常用，防过拟合 |

## 3.4 目标检测

### 三类视觉任务

- 分类：输出类别。
- 定位+分类：输出类别和单个框。
- 目标检测：输出多个目标的类别和框。

### IoU

```text
IoU = 预测框与真实框交集面积 / 预测框与真实框并集面积
```

一般 IoU >= 0.5 可认为定位成功，具体阈值看题目。

### Precision 与 Recall

```text
Precision = TP / (TP + FP)
Recall    = TP / (TP + FN)
```

阈值降低时，选中的预测更多，Recall 通常升高，Precision 可能降低。

### 两阶段与一阶段检测

| 类型 | 思路 | 代表 |
|---|---|---|
| 两阶段 | 先生成候选框，再分类和回归 | R-CNN、Fast R-CNN、Faster R-CNN |
| 一阶段 | 直接回归框和类别 | YOLO、SSD |

### R-CNN 系列脉络

- R-CNN：Selective Search 生成候选框，逐框 CNN 特征，慢且训练复杂。
- Fast R-CNN：整图一次卷积，ROI Pooling 复用特征，仍受 Selective Search 限制。
- Faster R-CNN：用 RPN 生成候选框，候选框生成也进入神经网络。

### YOLO

把检测看成单次回归问题。YOLO v1 将图像分成 `S x S` 网格，每格预测 `B` 个 bbox 和类别概率。优点是快，缺点是邻近小目标和定位精度较弱。

### SSD

一阶段检测，结合 anchor/default box 和多尺度特征图：大特征图检测小目标，小特征图检测大目标。

## 3.5 序列建模与 NLP 基础

### Token

token 是文本处理的基本单位，可为字符、词、子词。大模型按 token 计费。BPE 的核心是不断合并最频繁出现的一对 token。

### Embedding

embedding 将离散 token 转为固定维度连续向量。one-hot 稀疏且无法表达相似性；word2vec/Transformer embedding 是稠密向量，能表达语义相似。

### RNN

RNN 用隐状态保存历史信息：

```text
h(t) = f(W h(t-1) + U x(t) + b)
```

特点：序列输入、参数共享、具备记忆。问题是 BPTT 中长链式相乘会导致梯度消失或爆炸，只能较好处理短期依赖。

### LSTM 与 GRU

| 模型 | 结构 | 特点 |
|---|---|---|
| LSTM | 单元状态 + 遗忘门/输入门/输出门 | 表征强，能缓解长期依赖问题 |
| GRU | 更新门 + 重置门，合并状态 | 参数少、训练快 |

梯度爆炸常用梯度截断；梯度消失常用 LSTM/GRU 改进模型。

## 3.6 Seq2Seq 与注意力

Seq2Seq 用编码器把输入序列压成语义编码，再由解码器生成输出。缺点是固定长度语义编码难保存长序列全部信息，且各元素权重相同。

注意力机制给不同输入位置分配不同权重，让模型聚焦关键信息，并能并行计算。

### 缩放点积注意力

```text
Attention(Q,K,V)=softmax((QK^T / sqrt(d_k)) + Mask) V
```

流程：

1. `QK^T` 计算查询与键的相似度。
2. 除以 `sqrt(d_k)` 防止内积方差随维度变大导致 softmax 梯度过小。
3. 加 Mask 控制可见范围。
4. softmax 得到权重。
5. 乘 V 做加权汇聚。

### 自注意力

Q、K、V 都来自同一输入序列：

```text
Q = I W_Q, K = I W_K, V = I W_V
```

用于捕捉序列内部 token 之间的关系。

### 多头注意力

多组 Q/K/V 投影并行计算注意力，再拼接输出。不同头学习不同关系或知识。

## 3.7 Transformer

### 输入

token embedding + position encoding。原始 Transformer 位置编码使用不同频率的正弦/余弦函数，使模型知道 token 的顺序。

### Encoder

每层包含：

1. 多头自注意力，无 mask。
2. FFN 前馈网络。
3. 每个子层都有残差连接和 LayerNorm。

### Decoder

每层包含：

1. 带 mask 的多头自注意力，不能看未来 token。
2. 交叉注意力，Q 来自 decoder，K/V 来自 encoder。
3. FFN。
4. 残差连接和 LayerNorm。

### 训练与推理

训练时有标签，decoder 输入右移一位，可并行；推理时没有未来标签，只能自回归逐 token 生成。

## 3.8 大模型三类架构

| 架构 | 代表 | 适用 |
|---|---|---|
| Encoder-Decoder | Transformer、T5、GLM | 翻译、摘要、Seq2Seq |
| Encoder-only | BERT | 理解类任务，如分类、检索 |
| Decoder-only | GPT、LLaMA、DeepSeek | 生成类任务，大模型主流 |

### BERT

只使用 Transformer Encoder，双向无 mask。预训练任务包括 MLM 和 NSP。适合理解任务，不擅长自回归生成。

### GPT

只使用 Transformer Decoder 的 mask self-attention 和 FFN，自回归预测下一个 token。GPT-3 展示 in-context learning：zero-shot、one-shot、few-shot，不更新参数。

### Decoder-only 成为主流的原因

必背论述：

1. 生成任务天然适合自回归。
2. in-context learning 更强，prompt 直接作用于 decoder 每层。
3. causal attention 下三角矩阵满秩，建模能力强。
4. causal attention 带有隐式位置编码效果。
5. 推理可复用 KV cache，工程效率高。
6. Megatron、FlashAttention 等系统优化对 causal attention 支持成熟。
7. 实验证明 zero-shot/few-shot 泛化能力强。

## 3.9 大模型组件

- RoPE：旋转位置编码，在注意力中注入相对位置信息，适合长序列。
- RMSNorm：去掉 LayerNorm 的平移，只保留缩放，计算更简单稳定。
- SwiGLU：大模型常用 FFN 激活/门控结构。
- MHA/GQA/MQA：GQA 在性能与 KV cache 开销之间折中，MQA 所有 Q 共享 K/V。
- KV Cache：缓存历史 token 的 K/V，新 token 不必重复计算历史 K/V。

## 3.10 图像 Transformer

- DETR：把目标检测视为集合预测，减少 anchor、NMS 等手工部件。
- ViT：把图像切成 patch，当作 token 序列输入 Transformer Encoder。
- Swin Transformer：窗口内自注意力 + shifted window，降低计算并建立窗口间联系。

## 3.11 生成模型

### GAN

由生成器 G 和判别器 D 构成。D 学会分辨真假，G 学会骗过 D，是极小极大博弈。问题包括梯度消失和模式崩溃。CGAN 在输入中加入类别/条件，使生成可控。

### VAE

编码器输出隐变量分布参数而非固定向量，解码器从分布采样重构。损失 = 重构误差 + KL 散度。重参数化技巧：

```text
z = μ + εσ,  ε ~ N(0,1)
```

这样可以对 `μ` 和 `σ` 求导。

### 扩散模型

必背两个过程：

1. 正向扩散：从真实图像 `x_0` 开始逐步加入高斯噪声，最终接近标准正态。
2. 反向去噪：从噪声 `x_T` 开始逐步预测并去除噪声，恢复到真实数据分布。

训练本质是训练噪声预测器：输入时间步 `t` 和加噪图像，输出预测噪声。

### Stable Diffusion

Stable Diffusion 是隐扩散模型，在隐空间而非像素空间扩散。编码器把图像压到 latent，U-Net 在 latent 上预测噪声，最后解码回图像。优势是显著降低显存和计算量。

## 3.12 多模态模型

### CLIP

核心是图文双编码器 + 对比学习。用大规模图像-文本对训练，使匹配图文 embedding 相近、不匹配远离。推理时把类别标签转为文本，与图像 embedding 匹配，因此具备 zero-shot 能力。

### BLIP / BLIP-2

- BLIP：统一理解和生成，包含图文对比、图文匹配、语言建模损失，并用 CapFilt 清洗数据。
- BLIP-2：冻结视觉编码器和 LLM，只训练轻量 Q-Former，降低视觉语言对齐成本。

### VLA

VLA 指 Vision-Language-Action，把视觉输入、语言指令和动作输出统一到一个模型中，常用于机器人/具身智能。答题抓三点：

1. 视觉负责感知环境，语言负责表达任务和约束，动作负责和环境交互。
2. 训练通常需要图像/视频、语言指令、动作轨迹等多模态数据对齐。
3. 它与普通 VLM 的区别是：VLM 主要做理解/生成，VLA 还要输出可执行动作。

## 3.13 智能体 Agent

基于大模型的智能体通常包括三大部件：

1. 规划 Planning：任务分解与反思，如 CoT、ToT、ReAct、Reflexion。
2. 记忆 Memory：感知记忆、短期上下文记忆、长期外部向量数据库/RAG。
3. 工具 Tool Use：调用 API、函数、插件、外部模型等。

MCP 关注智能体与环境/工具交互，A2A 关注智能体之间协作通信。

## 3.14 神经网络量化

### 为什么量化

把 FP32/BF16 等高位宽数值离散化为 INT8/FP8/FP4 等低位宽表示和计算，降低计算量、存储、能耗和乘法器面积。

### 量化分类

| 分类角度 | 类型 |
|---|---|
| 对称性 | 对称量化、非对称量化 |
| 均匀性 | 均匀量化、非均匀量化 |
| 粒度 | 分层、分通道、分 token、分组/分块 |

### PTQ vs QAT

| 方法 | 过程 | 优点 | 缺点 |
|---|---|---|---|
| PTQ | 全精度训练后，用少量校准数据量化 | 简单、成本低 | 低位宽精度下降明显 |
| QAT | 量化后再微调/训练，前向模拟量化 | 低位宽精度更好 | 训练成本高 |

### KV 量化

KV cache 存历史 token 的 K/V。KV 量化降低内存占用和加载 KV cache 的时间，适合长序列和 decode 阶段。

## 4. 第四章 编程框架使用

### 4.1 Tensor 与普通矩阵区别

Tensor 是计算图上的数据载体，可运行在 CPU/GPU/DLP 上，支持自动求导和计算图。普通 NumPy 矩阵原生只能在 CPU 上运行，不支持深度学习框架的自动求导。

互相转换：

```python
torch.from_numpy(array)
tensor.numpy()
```

注意：CPU tensor 与 numpy 转换后通常共享内存；GPU tensor 转 numpy 需先 `.cpu()`。

### 4.2 Tensor 数据布局

- NCHW：batch、channel、height、width。PyTorch/GPU 常用，同通道像素连续，适合通道内操作。
- NHWC：batch、height、width、channel。TensorFlow/CPU 常见，同一像素不同通道连续，适合跨通道操作如 `1x1 conv`。

### 4.3 原位操作

带下划线的操作如 `add_()` 是 in-place，会直接修改原内存。优点是省内存；风险是训练时可能破坏计算图或梯度所需中间值。

### 4.4 广播机制

判断步骤：

1. 从最后一维开始对齐。
2. 每一维满足以下任一条件即可：
   - 两者尺寸相同。
   - 其中一个尺寸为 1。
   - 其中一个张量缺少该维，视为 1。
3. 任一维不满足则报错。

例：

```text
(2,3,3) 和 (3,1)
先把 (3,1) 补成 (1,3,1)
逐维比较：(2 vs 1), (3 vs 3), (3 vs 1)
可广播，结果形状为 (2,3,3)
```

原位广播限制：如果需要扩展的是执行原位操作的张量本身，会报错；如果扩展的是参数张量，可以。

### 4.5 计算图

计算图是用有向图描述计算过程。节点表示操作、输入、参数或输出；边表示张量流动或控制依赖。

### 4.6 静态图 vs 动态图

| 类型 | 特点 | 优点 | 缺点 | 代表 |
|---|---|---|---|---|
| 静态图 | 先建图再运行 | 便于全局优化，性能好 | 调试不方便 | TensorFlow 1.x |
| 动态图 | 边运行边建图 | 灵活、调试方便 | 优化空间小 | PyTorch |

现在主流框架通常同时支持动态图和静态图/编译模式。

### 4.7 `nn.Module` 与 `nn.functional`

- `torch.nn.xxx` 是模块类，通常在 `__init__` 中实例化，可以包含可学习参数。
- `torch.nn.functional.xxx` 是函数，在 `forward` 中调用，参数需自己管理。

### 4.8 `model.train()` 与 `model.eval()`

主要影响 Dropout 和 BN：

- `train()`：启用 Dropout，BN 使用 batch 统计并更新 running mean/var。
- `eval()`：关闭 Dropout，BN 使用训练得到的 running mean/var。推理前必须调用。

### 4.9 训练循环

```python
optimizer.zero_grad()
output = model(input)
loss = criterion(output, target)
loss.backward()
optimizer.step()
```

`zero_grad()` 是为了防止梯度累加。

## 5. 第五章 编程框架原理

### 5.1 框架四大模块

1. 计算图构建：用户程序转为内部计算图。
2. 计算图执行：把张量和算子映射到设备执行。
3. 深度学习编译：图级和算子级优化，提高单设备效率。
4. 分布式训练：扩展到多设备/多机。

### 5.2 设计哲学三性

- 简洁性：用户只需关注算法和部署策略。
- 易用性：接口直观、开发范式熟悉，如 PyTorch 的 Python 风格。
- 高效性：静态图优化、编译优化、分布式训练支持。

### 5.3 四种求导方法

| 方法 | 思路 | 缺点 |
|---|---|---|
| 手动求导 | 人手推公式再写代码 | 模型复杂时困难，模型变公式也变 |
| 数值求导 | 用差分近似导数 | 计算慢，有截断/舍入误差 |
| 符号求导 | 对表达式做代数求导 | 表达式膨胀 |
| 自动求导 | 前向建图，反向按链式法则传播 | 框架实现复杂，但最适合深度学习 |

自动求导不是简单数值求导，也不是完全符号求导；它对基本算子使用已知导数，在运行时保存中间结果并反向传播。

### 5.4 自动求导两步

1. 正向：构建计算图，计算并保存中间节点。
2. 反向：从输出开始反向遍历，按链式法则计算每个节点梯度。若一个节点连接到多个后继，梯度要累加。

### 5.5 计算图执行（了解）

老师提到这一块以了解为主，但要知道框架执行计算图大致包含：

1. 设备管理：识别 CPU/GPU/DLP 等设备，管理执行流、事件和同步。
2. 张量实现：张量有逻辑视图和物理存储，切片/reshape 可能只是逻辑视图变化。
3. 算子执行：根据计算图依赖得到执行序列，再按设备类型分派到对应后端 kernel。

这部分通常不会要求深入代码实现，重点是知道“计算图执行”负责把图中的张量和算子真正映射到设备上运行。

### 5.6 深度学习编译为什么重要

早期框架依靠厂商库和手写算子，维护成本高，且难以充分探索全图优化空间。深度学习编译器用多层级 IR 和多层级优化，自动生成高性能代码，适配不同硬件。

### 5.7 图级优化 vs 算子级优化

| 类型 | 判断关键词 | 例子 |
|---|---|---|
| 图级优化 | 不关心单个算子内部实现，只看图中数据流 | 子图替换、常量折叠、公共子表达式消除、代数化简、布局优化、算子融合 |
| 算子级优化 | 深入算子内部循环和硬件代码 | tiling、vectorize、parallel、unroll、SIMD、自动调优 |

考试分类技巧：题干里如果是“把多个算子合并、删重复节点、改图结构”，多半是图级；如果出现“循环分块、向量化、缓存命中、底层循环”，多半是算子级。

### 5.8 分布式训练两种架构

| 架构 | 思路 | 优点 | 缺点 |
|---|---|---|---|
| 参数服务器 | Server 存参数并更新，Worker 计算梯度 | 灵活、共享方便 | 中心瓶颈、单点故障、一致性问题 |
| 集合通信 | 无中心节点，多节点点对点同步 | 去中心化，常用于大规模训练 | 对网络和同步要求高 |

### 5.9 集合通信原语

| 原语 | 操作 | 常见用途 |
|---|---|---|
| Broadcast | 一到多广播 | 初始化/同步模型参数 |
| Scatter | 一到多切块分发 | 分发数据或权重片段 |
| Gather | 多到一收集 | 收集梯度/结果 |
| All-Gather | 每个节点收集所有节点数据 | 数据同步，模型并行中拼接结果 |
| Reduce | 多到一归约 | 梯度求和到主节点 |
| All-Reduce | 归约后广播给所有节点 | 分布式梯度平均最常用 |
| Reduce-Scatter | 先归约再散射 | ZeRO/FSDP 中常见 |
| All-to-All | 多对多交换 | 张量/序列并行的数据重排 |

### 5.10 并行策略

| 策略 | 切分对象 | 解决问题 |
|---|---|---|
| 数据并行 | 输入数据 | 单设备算力不足 |
| 模型并行 | 模型参数/层/算子 | 单设备内存不足 |
| 张量并行 | 单个算子内部张量 | 大矩阵乘等单算子太大 |
| 流水并行 | 不同层放不同设备 | 模型层数太多，参数放不下 |
| 序列并行 | token/序列维度 | 长上下文 attention 太大 |
| 混合并行 | 同时切数据和模型 | 超大模型训练 |

## 6. 第六章 处理器原理

### 6.1 通用处理器跑深度学习的问题

真实处理器中真正用于运算的面积不到 1%，大量面积用于控制、缓存、寻址。深度学习运算虽规整，但在通用处理器上每个数据访问仍要地址计算和控制判断，控制/寻址开销很大。

### 6.2 向量处理器

向量处理器用一条指令并行操作多个数据，摊薄控制和寻址开销。GPU 是典型向量/SIMD/SIMT 风格处理器。问题是向量化不改善单位运算的访存比例，访存瓶颈仍严重。

### 6.3 I/O 复杂度

关键结论：

| 运算 | 运算量 | I/O 量 | 局部性 |
|---|---|---|---|
| 标量乘 | 1 | 3 | 差 |
| 向量运算 | n | 3n | 未改善 |
| 矩阵乘向量 | n² | n² | 一般 |
| 矩阵乘矩阵 | n³ | n² | 最好 |

矩阵乘矩阵的运算/I-O 比随规模增大而增大，是 DLP 重点加速矩阵运算的理论依据。

### 6.4 DLP 矩阵运算单元

DLP 的核心是把基本运算单元从向量扩展到矩阵。

| 处理器 | 运算单元 | 数据通路 |
|---|---|---|
| 标量处理器 | 1 | 2 |
| 向量处理器 | n | 2n |
| DLP 矩阵处理器 | n² | 3n |

结论：DLP 在相同带宽下可提供更高运算能力。

### 6.5 传统矩阵电路的问题

简单堆叠 `n²` 个运算单元会带来：

- 连线距离远。
- 扇出多。
- 时序和功耗恶化。

因此需要脉动阵列等新结构，让数据在阵列中局部、逐拍流动。

### 6.6 DLP 三大结构设计

1. 计算：矩阵运算单元为核心，辅以向量/标量。
2. 存储：使用便笺存储器 scratchpad，而非完全依赖 cache。
3. 控制：深度学习多是计数循环，可简化分支预测等复杂控制。

典型搭建步骤：精简通用处理器 → 取消数据 cache → 加便笺存储器和 DMA → 加矩阵运算单元 → 加矩阵指令控制单元。

### 6.7 便笺存储器与 DMA

Cache 对程序透明，由硬件自动管理；便笺存储器由软件显式管理。深度学习访存规律强，适合用便笺存储器。DMA 负责主存与便笺之间的大块连续数据搬运。

### 6.8 多核与分形扩展

简单放大单个矩阵单元会导致利用率下降，因为实际算子尺寸未必能填满超大阵列。更灵活的方式是多个较小矩阵单元、多核、组件嵌套，并用分形方式扩展。分形 DLP 指用相同规则递归扩展，用户视角保持一致。

## 7. 第七章 处理器架构

### 7.1 DLP 两大结构特点

必背：

1. 取消传统输入，直接用 IO 连接外部。
2. 增设便笺存储器从机，通过 DMA 直接访问外部 DRAM，而不是依赖传统 cache 层次。

优势：DLP 可一条 load 装载整块数据，一条指令完成计算，一条 store 写回，显著减少通用处理器中大量 load/store、控制、寻址开销。

### 7.2 计算单元

DLP 中矩阵、向量、标量单元共存：

- 矩阵单元：矩阵乘、卷积等核心高密度计算。
- 向量单元：池化、归一化、激活、Softmax 等。
- 标量单元：控制、少量标量计算、特殊逻辑。

### 7.3 矩阵单元逐级组合

基本思路：

乘法器 → 内积单元 → 矩阵乘向量单元 → 矩阵乘矩阵单元。

优化方向：

- 权值靠近计算单元存放。
- 激活值广播共享。
- 多个内积单元并行。
- 多个矩阵乘向量单元组合。

目标始终是提高计算-I/O 比例。

### 7.4 脉动阵列

脉动阵列中，激活值和权值从不同方向进入二维 PE 阵列，每个 PE 做乘加并把数据传给邻居。优势：

- 局部短连接。
- 扇出少。
- 计算-I/O 比更好。
- 特别适合矩阵乘和卷积。

困难：

- 有启动和排空延迟。
- 专用性强，难高效支持所有操作。

### 7.5 向量/标量单元功能

常用于：

- 池化：AvgPool、MaxPool。
- 归一化：BatchNorm 等。
- 激活函数：ReLU、Sigmoid、Tanh，可用分段线性近似。
- 前缀计算：前缀和、计数、归约。
- 数据重排布：排列网络如 Beneš/Waksman。

### 7.6 便笺存储器设计

便笺存储器是 DLP 核内数据枢纽。缓解访问拥堵的两类思路：

1. 拓宽道路：多端口 SRAM、分 bank SRAM。
2. 规划车流：分离式便笺，如按神经元/权值、矩阵/向量/标量、输入/输出/累加器划分。

权衡：效率提升往往以通用性下降和硬件成本增加为代价。

### 7.7 软件流水线

DLP 外存访问可持续很多周期。软件流水线将 `load / compute / store` 在 DMA 模块和计算模块上交叠执行，由编译器或程序员重排指令，并用显式 sync 同步。这样可简化硬件，不需要复杂乱序执行和依赖检查。

### 7.8 通信拓扑

多核/多卡 DLP 中：

- 数据并行常用 All-Reduce。
- 算子内并行可能用 All-to-All。
- 算子间并行多为局部通信。

物理链路可用总线、NoC、交叉开关。环形 All-Reduce 可用 ring 高效实现，但物理拓扑不一定必须是环。

## 8. 第九章 大模型计算系统

### 8.1 大模型计算系统组成

大模型计算系统是算法、系统软件和基础硬件的协同设计。训练需求随参数规模和数据规模增长，而芯片算力增长跟不上模型需求，因此必须系统优化。

### 8.2 大模型发展历史

语言模型从统计语言模型发展到神经语言模型，再到 RNN/Seq2Seq/Transformer，最终进入大模型时代。架构上从 Encoder-Decoder、Encoder-only 逐渐发展到 Decoder-only 成为主流。

### 8.3 BLOOM 例子

BLOOM-176B 采用混合并行：

```text
数据并行度 8 x 张量并行度 4 x 流水线并行度 12 = 384 GPU
```

张量并行和数据并行常用 All-Reduce，流水线并行常用点对点通信。

训练存储包括：

- 模型权重。
- 优化器状态，如 AdamW 的权重、动量、方差。
- 梯度。
- 激活值。

### 8.4 大模型优化三分类

必背：

1. 计算优化。
2. 存储优化。
3. 稳定性优化。

### 8.5 计算优化

训练：

- 稀疏注意力：利用注意力稀疏性减少计算。
- 专用数据类型：TF32、BF16、FP16 等混合精度。

推理：

- 批处理优化：连续批处理比静态批处理吞吐更高。
- KV cache：缓存历史 K/V，避免重复计算。

### 8.6 存储优化

#### ZeRO 零冗余优化器

数据并行下，每张卡都存优化器状态、梯度、权重，存在冗余。ZeRO 将这些状态分片到不同 GPU，用时再 all-gather/broadcast 重建。

三类策略：

- ZeRO：切分权重、梯度、优化器状态。
- ZeRO-Offload：把部分参数/状态卸载到 CPU。
- ZeRO-Infinity：进一步利用 NVMe SSD 等高速存储。

#### 重计算

正向只保存部分激活作为检查点，反向需要时重新计算中间激活。用计算换存储，可显著降低激活存储，但增加计算量。

#### FlashAttention

Attention 中 `S=QK^T`、`P=softmax(S)` 等中间矩阵很大。FlashAttention 通过分块和融合，不把大中间结果写回显存，降低片外访存，提高效率。

#### KV Cache 分页

KV cache 长度动态变化，直接连续分配会有严重碎片。分页思想把 KV cache 分块，块内连续、块间可不连续，降低浪费。

### 8.7 稳定性优化

老师重点。大模型训练时间长、设备多，故障频繁。遇故障的处理方式：

1. Checkpoint：定期保存训练状态，故障后回滚恢复。
2. Elastic training：训练资源变化或故障后能弹性恢复，减少停机。
3. Redundant computations：用冗余计算提高容错能力。

答题时要强调：大规模系统中故障是常态，不做稳定性优化会浪费巨大训练资源。

### 8.8 通信与硬件

通信优化目标是减少传输量、提高通信效率、降低通信与计算竞争。RDMA 通过零拷贝和内核旁路实现高吞吐、低延迟、低 CPU 开销。集群拓扑中张量并行通信开销最大，通常限制在服务器本地；流水线并行更适合跨服务器扩展。

## 10. 计算题模板

### 10.1 卷积输出尺寸

题型：输入 `32x32x3`，卷积核 `5x5`，padding=2，stride=1，输出通道 64。

步骤：

```text
W_o = floor((32 + 2*2 - 5)/1) + 1 = 32
H_o = floor((32 + 2*2 - 5)/1) + 1 = 32
输出形状 = 32 x 32 x 64
参数量 = 64 x 5 x 5 x 3 + 64 = 4864
```

### 10.2 全连接参数量

题型：输入 100，隐藏层 50，输出 10。

```text
第一层 = 100 x 50 + 50 = 5050
第二层 = 50 x 10 + 10 = 510
总参数 = 5560
```

### 10.3 IoU

步骤：

1. 算两个框交集宽高：  
   `inter_w = max(0, min(x2_A,x2_B) - max(x1_A,x1_B))`  
   `inter_h = max(0, min(y2_A,y2_B) - max(y1_A,y1_B))`
2. 交集面积：`inter = inter_w x inter_h`
3. 并集面积：`area_A + area_B - inter`
4. IoU：`inter / union`

### 10.4 广播

题型：判断 `(2,3,1)` 与 `(3,4)` 能否广播。

```text
(3,4) 补成 (1,3,4)
比较：
2 vs 1 -> 可
3 vs 3 -> 可
1 vs 4 -> 可
结果形状 (2,3,4)
```

题型：`(2,3)` 与 `(2,2)`。

```text
末维 3 vs 2，不同且都不是 1 -> 不可广播，报错
```

### 10.5 注意力

题型一般给 Q、K、V 小矩阵。步骤：

1. 算 `QK^T`。
2. 除以 `sqrt(d_k)`。
3. 如有 mask，把不可见位置加 `-inf`。
4. 对每行 softmax。
5. 权重矩阵乘 V。

### 10.6 集合通信选择

| 场景 | 选什么 |
|---|---|
| 主节点把初始参数发给所有节点 | Broadcast |
| 各节点梯度求平均并让所有节点得到结果 | All-Reduce |
| 各节点数据收集到一个节点 | Gather |
| 所有节点都得到所有节点的数据 | All-Gather |
| 先把梯度求和，再把不同分片分给不同节点 | Reduce-Scatter |
| 多节点互相交换不同分片 | All-to-All |

## 11. 最后冲刺自测

### 11.1 看到题目必须能秒答

- CNN 减少参数靠什么？局部连接、权重共享。
- 神经网络“卷积”和数学卷积区别？神经网络不翻转卷积核，本质是相关/内积。
- padding 的作用？控制输出尺寸，保留边缘信息。
- stride 的作用？控制滑动步长和下采样程度。
- ReLU 的问题？负区梯度为 0，可能死亡。
- 交叉熵为何比 MSE 更适合 sigmoid 分类？能抵消 sigmoid 导数，缓解梯度小。
- 过拟合怎么办？正则、稀疏、Bagging、Dropout、早停、数据增强。
- RNN 为什么学不了长期依赖？BPTT 长链相乘导致梯度消失/爆炸。
- LSTM 三个门？遗忘门、输入门、输出门。
- GRU 两个门？更新门、重置门。
- Transformer 为什么要位置编码？自注意力本身不含顺序信息。
- Decoder mask 作用？防止看到未来 token，满足自回归。
- BERT 和 GPT 区别？BERT encoder-only 双向理解；GPT decoder-only 自回归生成。
- 扩散模型两个过程？正向加噪、反向去噪。
- Stable Diffusion 快在哪里？在隐空间扩散，降低显存和计算。
- CLIP 怎么训练？图文双编码器对比学习。
- Agent 三部件？规划、记忆、工具。
- PTQ 和 QAT 区别？PTQ 校准不训练；QAT 量化后微调。
- Tensor 和 NumPy 区别？Tensor 支持 GPU/DLP、自动求导、计算图。
- 静态图优点？全局优化、运行快。
- 动态图优点？灵活、易调试。
- 自动微分优于数值求导在哪里？精度高、效率高，适合大规模参数。
- DLP 核心运算单元？矩阵运算单元。
- 脉动阵列解决什么？传统矩阵单元连线远、扇出多。
- DLP 两大结构特点？IO 直连外部；便笺存储器 + DMA 访问 DRAM。
- 大模型优化三分类？计算优化、存储优化、稳定性优化。
- ZeRO 解决什么？数据并行状态冗余，通过分片降低存储。
- 稳定性优化重点？checkpoint、弹性训练、冗余计算。

### 11.2 易混点

- 退化问题不是过拟合：ResNet 解决的是深层网络训练误差升高。
- BN 不等于 LN：BN 跨 batch，LN 在样本内部。
- Dropout 训练用、推理不用。
- KV cache 是推理加速/存储优化关键，不是训练参数。
- FlashAttention 主要省片外访存，不是简单减少数学公式里的 attention 计算定义。
- ZeRO 是存储优化，不是计算优化。
- All-Reduce 是所有节点都有归约结果；Reduce 只有一个节点有结果。
- 图级算子融合属于图级优化；融合后生成高效 kernel 的循环调度属于算子级优化。

## 12. 一页背诵版

深度学习基础：梯度下降沿负梯度更新；激活函数引入非线性；交叉熵适合分类；过拟合靠正则、Dropout、早停、增广等缓解。CNN 靠局部连接和权重共享减少参数；卷积输出尺寸看 input、padding、kernel、stride；VGG 用小卷积加深，Inception 用多分支和 `1x1` 降维，ResNet 用残差解决退化。

序列模型从 RNN 到 LSTM/GRU，再到 Seq2Seq 和注意力。注意力用 Q/K 相似度给 V 加权，Transformer 用多头自注意力、位置编码、残差和 LN。BERT 是 encoder-only，适合理解；GPT 是 decoder-only，自回归生成，因 in-context learning、KV cache、causal attention 和工程优化成为主流。

框架层面，Tensor 支持设备和自动求导；计算图分静态图和动态图；自动微分通过正向建图、反向链式求导实现。编译优化分图级和算子级；分布式有参数服务器和集合通信，数据并行常用 All-Reduce。

DLP 用矩阵运算单元提高计算/I-O 比，传统矩阵阵列连线远、扇出多，因此用脉动阵列。DLP 使用便笺存储器和 DMA，减少通用处理器控制、寻址、cache 开销。大模型系统优化分计算、存储、稳定性；存储重点 ZeRO、重计算、FlashAttention、KV cache 分页；稳定性重点 checkpoint、弹性训练和冗余计算。
