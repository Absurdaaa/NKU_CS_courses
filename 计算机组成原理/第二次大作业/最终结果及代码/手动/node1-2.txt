R型指令：所有操作数均来自寄存器，运算结果也直接写回寄存器，可高效执行寄存器间的算术/逻辑运算，格式如下：操作码 目标寄存器,源寄存器1,源寄存器2 [,移位/扩展操作]
ADD：加法指令，ADD X0,X1,X2实现X0 = X1 + X2
SUB：减法指令，SUB X0,X1,X2实现X0 = X1 - X2
ADC：带进位加法，ADC X0,X1,X2实现X0 = X1 + X2 + Carry（进位标志）
AND：逻辑与指令，AND X0,X1,X2实现X0 = X1 & X2
ORR：逻辑或指令，ORR X0,X1,X2 实现X0 = X1 | X2
EOR：按位异或，EOR X0,X1,X2实现X0 = X1 ^ X2
BIC：位清除，BIC X0,X1,X2实现X0 = X1 & (~X2)
LSL：逻辑左移，LSL X0,X1,#4实现 X0 = X1 << 4（等价于X1*16）
LSR：逻辑右移，LSR X0,X1,#3 实现 X0 = X1 >> 3（高位补0）
ASR：算术右移，ASR X0,X1,#2实现X0 = X1 >> 2（高位补符号位）
ROR：循环右移，ROR X0,X1,#8实现 X0 = 将X1循环右移8位
MOV：MOV X0,X1实现X0 = X1（拷贝值）
CLZ：前导零计数，CLZ X0,X1计算X0 = X1二进制值中前导零的数量
REV：字节反转，REV X0,X1计算X0 = X1的字节顺序反转（大端←→小端转换）
CMP：比较指令，CMP X1,X2计算X1 - X2，并根据结果更新标志位（NZCV）
