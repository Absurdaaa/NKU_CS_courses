Discussion · Limitations

Clover 解决了核心聚合问题，但部署仍有边界

论文的设计重点是让 top-k、安全聚合和 DP 同时成立；真正落地时，还需要面对信任组织、系统复杂度和威胁模型边界。

Core contribution Clover

top-k 稀疏上传 + 安全聚合 + DP 输出保护

Trust

三服务器部署

需要不同信任域支撑“不完全合谋”假设。

System

协议链路变长

shuffle、聚合、噪声和恶意检查都提高实现成本。

Threat model

不覆盖所有攻击

不能直接替代投毒、后门和异常客户端检测。

结论：Clover 更像一个面向 top-k 稀疏联邦学习的安全聚合与 DP 框架，而不是完整替代联邦学习部署中的所有安全机制。
