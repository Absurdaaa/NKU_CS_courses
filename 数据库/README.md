# 省流建议

不知道明年计卓还会不会做继续bustub。计卓的学弟学妹请注意，如果觉得自己c++代码能力一般的，速run，甚至最好run网安的数据库课程。

# 几桌数据库详情

几桌的课程要求做CMU的配套数据库课程的实验，首先代码框架是很底层的数据库，老师上课大概讲理论较多，部分底层其实光听课还是不会做实验。然后每年的这个课程的每章节实验都会有小改动，到我们这年改动还蛮大了，就没有太多网上的资料可以借鉴，知乎还有一些博客会比较多。但是多归多，需要花费学习这个数据库底层框架的时间是很多的，需要你慢慢看代码去理解框架，理解每一部分的作用是什么。

实验难度并不小，我们今年本来有30多个人上课，期中的时候退了十多个人，如果你只会用ai并且还用的不咋地，建议还是选其他课。

差不多一个月一次的实验提交，我们这年也是和助教商量之后延期到期末周后一两个星期，属实是超级宽松了，其实压力也不会很大，但是对比其他普通班的数据库课来说，性价比并不是很高。

# 为什么建议选

如果你大一的c++功底尚可，那么这个课是一个很好的培养你的工程框架能力（不知道这个表述对不对）的机会，在设计很多类和辅助函数的时候，其实是需要考虑很多上下文关联的其他函数的，更是要考虑复用性，不然就容易变成史山代码了。

大二其实时间尚可，做完bustub会对数据库底层有一定的理解，在快结课课刚好会有一两个数据库比赛可以去打一下。我和我的同学去年就参加了一个数据库的国赛并拿了二等奖，我们的阵容是两个坚持做完bustub的几桌同学+一个普通班的同学，我们两个做过bustub之后再来做国内的一些比赛提供的框架，相当得心应手，甚至觉得有点框架烂。但是得心应手不代表我们做的很强，最后性能还是赶不上别人，不过我们保留的较多的完整资料，就靠学弟学妹们去传承比赛了！
