# 问题描述
给定一个稀疏矩阵，每行是一个用户，每列代表一个item。矩阵中的值表示用户对物品的评分。

我们需要实现一个推荐系统，给定每个用户需要预测的物品，需要得到这个用户对这个物品的评分。

# 作业实现


### 权重计算
主要是用协同过滤方法去预测。这里有两种方法：（CF）
* 基于用户的协同过滤
* 基于物品的协同过滤
（ppt说基于物品更好，当然，推荐两者结合）
  
* 1.基于用户的协同过滤是通过计算用户之间的相似度来预测评分。我们可以使用余弦相似度、皮尔逊相关系数等方法来计算用户之间的相似度。

缺失的评分我们设置为0，并且每行减去每行的均值（感觉是为了防止一些不想交的用户评分影响相似度，详情看ppt1


  
* 2.基于物品的协同过滤是通过计算物品之间的相似度来预测评分。我们可以使用余弦相似度、皮尔逊相关系数等方法来计算物品之间的相似度。


我们用上面的相似度来计算评分。我们可以使用加权平均的方法来计算评分。
这里还推荐了用最近的k个向量去加权评分，而不是全部（这个k邻近算法是主要运行开销！！）
