#### 一、为什么用时钟边缘（下降沿）做控制信号？

答：如果在整个时钟高电平期间都允许状态变化，那么电路可能会连续变化、产生竞争与冒险。而使用“边沿触发”后，状态只会在某一个瞬间改变一次，电路更稳定、更容易同步。

边沿触发可以避免组合逻辑传播过程中反复更新，并且保证所有寄存器同步更新，同时防止竞争冒险和简化时序分析。



为什么是下降沿，这个是统一约定的，方便对齐。但是有时候可能会一部分用上升沿一部分用下降沿，能够错开更新的时间，防止读写冲突。

#### 二、`_gmon_start_` 的含义

__gmon_start__是 GNU profiling（性能分析）相关函数。用于gprof、程序性能统计、函数调用采样

如果程序开启‘-pg’，编译器会插入 profiling 初始化代码。

即使没主动开启，链接器也可能自动加入‘\_\_gmon\_start\_\_()’。因为glibc、gcc这些会自动生成初始化流程。

#### 三、为什么 `ori` 是 0 扩展，而 `load/store` 是符号扩展？

MIPS 的 I 型指令中包含 16 位 immediate，需要扩展成 32 位再参与运算。

`ori` 属于逻辑运算：

```asm
ori rt, rs, imm16
```

本质是按位或，不涉及正负数，因此高位补 0 更符合逻辑运算的含义。

而 `lw/sw` 中的 immediate 表示地址偏移量：

```asm
lw rt, imm(rs)
```

地址计算方式为：

```c
addr = rs + offset
```

这里 offset 可能是负数，例如：

```asm
lw $t0, -4($sp)
```

表示访问栈顶上方的数据，因此必须支持负偏移，所以 `load/store` 使用符号扩展。
